# Portfolio 投资观点

投资观点是 Portfolio 私域的 PM 判断记录，与量化 Research、个人研究助手对话和 Watchlist 单资产观点分别保存。它不依赖 Research 运算开关，不会产生交易、修改配置、触发计算或自动同步到团队单资产研究。

## 一条组合时间线

每条记录包含判断日期、正文、当时背景，以及可选标题、来源文本和一个或多个已登记共享资产。作者、记录时间和更正人由服务端真实身份与时钟生成；判断日期不代替记录时间。来源可以是材料名称、URL 或带分析日期、结论与口径的摘录，不自动抓取链接。引用量化研究时应把这些最小信息写入背景或来源，不能仅依赖可能随旧 Research run 清理而失效的产物链接。

未选择资产表示组合整体判断；选择资产表示这些资产在本组合中的观点或持有理由。同一资产可以在不同组合中承担不同角色。关联不要求当前持仓，建仓前与清仓后均可保留。持仓详情中的「本组合投资观点」只按共享资产筛选同一时间线，不另存持仓笔记。FCN、Option 及现金的 Portfolio-local 持仓 ID 不作为共享资产关联；不支持在此绑定本地合约。资产名称和类型随版本保存其当时身份，之后改名不重写历史记录。

## 作者、修订与当前观点

组合 viewer 可以阅读时间线与全部版本；editor、manager 可以追加新判断及选择总体观点。更正限原作者或 manager，原作者保持不变，本版本更正人另行记录。每次更正追加不可变版本；没有删除单条观点的接口。仅选择未限定关联资产的整体判断，才能设为「当前总体观点」，并绑定具体 `note_id + revision_number`。新增观点、更正旧观点或读取研究助手回答均不会改变选定版本；可以明确取消选定。

所有接口沿用逐组合 ACL，团队管理身份没有隐含组合权。服务身份与研究委托不能写观点。跨组合的记录或版本 ID 不可读取、更正或引用为本组合总体观点。复制组合不复制观点；删除组合仍由既有 manager 确认流程控制，观点和修订随组合删除。

更正提交读取时的 `expected_revision`，总体观点选择或取消提交 `expected_version`；服务端在同一事务内比较版本、写修订／选择和审计。并发过期请求返回 409，不覆盖已发布结果。页面保留冲突草稿，重新读取不会悄悄把它改为最新版本；用户核对最新记录后再开始更正。切换组合或资产筛选时旧请求结果失效，提交中不能重复保存。

## API 与存储

所有路径以 `/api/portfolios/{portfolio_id}/investment-views` 为根：

| 方法与路径 | 行为 |
| --- | --- |
| `GET /` | 最新修订组成的时间线、显式选定总体观点与选择版本；可选 `instrument_id` 筛选时间线 |
| `GET /instruments` | 只读轻量共享资产目录，不建档、不获取行情、不依赖持仓 |
| `POST /` | 追加新判断 |
| `PUT /{note_id}` | 更正并追加版本 |
| `GET /{note_id}/revisions` | 阅读该组合内记录的历史版本 |
| `PUT /current-stance` | 选定具体版本；`note_id` 与 `revision_number` 同时为空表示取消 |

迁移 `20261008_0071`（父版本 `20260929_0070`）新增 `portfolio_investment_view`、`portfolio_investment_view_revision`、`portfolio_investment_stance`。总体观点使用包含 `portfolio_id` 的复合外键引用修订，数据库也拒绝跨组合引用。迁移不需要重建金融 read model。空表可降回父版本；存在人工观点后拒绝降级，需恢复升级前备份或向前修复，不能直接丢弃判断历史。
