# Fund 定性研究框架

- 状态：Current baseline
- 日期：2026-05-01
- 适用范围：watchlist fund detail 的 `Research` 页、watchlist research label columns、后续研究复盘

## 1. 设计原则

定性研究标签是机构研究结论，不是自由备注。

本框架借鉴主权基金、捐赠基金、养老金和大型 FOF 在外部管理人研究中的常见尽调结构：先确认资产与策略身份，再判断可持续优势、流程可复制性、团队稳定性、组合构建、风险管理、容量、条款、治理和组合角色。标签只表达可被证据支持的当前结论，不能替代研究笔记。

使用原则：

1. 标签必须从受控选项中选择，不允许临时自造同义词。
2. 每个标签选择前必须有证据来源，证据可以来自披露材料、访谈、持仓和业绩归因、合同条款、风控记录或内部复盘。
3. 定性标签描述“为什么值得研究/配置/回避”，不描述是否已经持仓；是否 `Invested / Proposed / Watch / Paused / Exited` 属于投资生命周期状态。
4. Notes 是事实、观察和推理过程；Tags 是从 notes 和材料中沉淀出的结构化结论。
5. 标签至少在经理变更、策略漂移、规模大幅变化、连续异常回撤、条款变化或投委会复核时重新评估。

## 2. Research 页结构

Research 页分为四块：

1. `Qualitative Research Tags`
   受控标签框架，按本文件定义的维度、项目和选项选择。
2. `Research View`
   当前研究观点文字，例如 `High Conviction / Constructive / Neutral / Cautious / Avoid / Under Review`。不要命名为 `Research Status`，避免和投资生命周期状态混淆。
3. `Research Notes`
   统一笔记时间线，与 Overview chart 上的 notes 使用同一份 `timeline_notes` 数据。
4. `Rating`
   人工星级，表达研究员当前 conviction / 优先级，不等同于量化评分 `overall_rating`。

辅助字段：

- `DD / ODD / IC`
  可以保留为尽调、运营尽调和投委会流程状态，但不进入定性标签 vocabulary。

## 3. 评分规则

`Rating` 采用 1 到 5 星。

| 星级 | 标准 |
| --- | --- |
| 5 | 高 conviction。优势清晰、流程可重复、团队与风控稳定，且适合进入核心或高优先级候选池。 |
| 4 | 重点观察或可配置。主要假设成立，但仍有容量、环境、条款或数据验证问题需要跟踪。 |
| 3 | 正常观察。产品有研究价值，但优势、角色或风险补偿尚未形成强结论。 |
| 2 | 低优先级。存在明确短板，只有在特定市场环境或组合缺口下才继续跟踪。 |
| 1 | 回避或归档。核心假设不成立、风险不可接受、透明度不足或条款/治理不匹配。 |

星级必须能在 `timeline_notes` 中找到原因。

## 4. 标签维度

### 4.1 Research Governance

研究覆盖与证据充分度。它描述研究工作的当前质量，不描述是否持仓。

#### `focus_bucket`

| 选项 | 标准 |
| --- | --- |
| Tier 1 | 近期研究优先级最高，通常对应核心候选、重大变化或高 conviction 复核。 |
| Tier 2 | 正常覆盖，定期更新即可。 |
| Tier 3 | 低频观察，除非触发事件，否则不占用重点研究资源。 |

#### `research_evidence_level`

| 选项 | 标准 |
| --- | --- |
| 完整证据 | 已有文档、访谈、业绩归因、持仓/风险验证和条款检查，能支撑投委会讨论。 |
| 部分证据 | 有核心材料，但缺少至少一类关键验证，例如风险、持仓或条款。 |
| 轶事证据 | 主要来自销售材料、单次交流或短期表现，尚不足以结构化判断。 |
| 待验证 | 还没有足够材料形成结论。 |

### 4.2 Edge And Philosophy

判断产品是否有清晰、可解释、可持续的收益来源。

#### `investment_edge_quality`

| 选项 | 标准 |
| --- | --- |
| 清晰且可持续 | 收益来源清楚，能通过流程、数据、团队能力或市场结构解释，并跨周期验证。 |
| 清晰但需验证 | 投资逻辑清楚，但历史周期、规模、团队或数据验证不足。 |
| 主要是市场贝塔 | 收益大多来自市场/风格暴露，不应被误判为稳定 alpha。 |
| 边际优势不清 | 无法解释长期胜率来源，或材料与实际表现不一致。 |

#### `alpha_source`

可多选，但只选真正长期贡献收益的来源。

| 选项 | 标准 |
| --- | --- |
| 选股Alpha | 超额主要来自公司/证券选择。 |
| 指数复制 | 主要目标是复制基准或规则指数。 |
| 贝塔增强 | 在基准暴露上做可解释增强。 |
| 趋势跟踪 | 收益来自趋势识别和持有。 |
| 期限结构 | 收益来自期限结构、曲线或展期。 |
| 价差收敛 | 收益来自相对价值价差回归。 |
| 波动率交易 | 收益来自波动率定价、曲面或期权结构。 |
| 事件驱动 | 收益依赖并购、重组、定增、打新等事件。 |
| 宏观择时 | 收益来自宏观方向、资产轮动或政策周期判断。 |
| Carry/票息 | 收益来自票息、期限溢价、信用利差或 carry。 |
| 主题/风格暴露 | 收益来自稳定主题、行业或风格风险溢价。 |
| 高频/微观结构 | 收益来自交易执行、订单流或市场微观结构。 |

### 4.3 Process Repeatability

判断研究、决策、交易和复盘是否可复制。

#### `implementation_style`

| 选项 | 标准 |
| --- | --- |
| 主观 | 主要依赖投资经理/团队主观研究与判断。 |
| 量化 | 主要依赖模型、数据和系统化交易流程。 |
| 主观+量化 | 主观研究和量化模型都有实质贡献。 |
| 被动规则 | 主要依据指数、规则或合同约束执行。 |

#### `process_repeatability`

| 选项 | 标准 |
| --- | --- |
| 可重复 | 流程清晰、职责明确、组合结果能被流程解释。 |
| 部分可重复 | 主流程存在，但关键环节仍依赖少数人判断或临场经验。 |
| 关键人驱动 | 投资结果高度依赖单个投资经理或创始人。 |
| 不透明 | 无法充分理解其研究、交易或风控流程。 |

#### `decision_discipline`

| 选项 | 标准 |
| --- | --- |
| 证据驱动 | 决策和复盘依赖可验证数据、投资备忘录或清晰记录。 |
| 经验驱动 | 决策主要来自资深人员经验，但复盘机制尚可。 |
| 机会型 | 仓位和交易较依赖短期机会，组合稳定性较弱。 |
| 不清晰 | 无法判断决策纪律。 |

### 4.4 Portfolio Construction

判断产品如何把想法落到仓位、约束、换手和风险暴露上。

#### `portfolio_construction`

可多选，只选会长期影响持有人体验的构建特征。

| 选项 | 标准 |
| --- | --- |
| 集中持仓 | 单一证券、行业或策略暴露较高，个体判断影响大。 |
| 分散持仓 | 单一风险贡献较低，依赖广泛机会集。 |
| 行业集中 | 长期或阶段性行业暴露较重。 |
| 风格均衡 | 主动控制价值/成长、市值、行业等风格暴露。 |
| 严格基准约束 | 跟踪误差、行业偏离或久期偏离受明确限制。 |
| 低跟踪误差 | 产品体验更接近基准或指数增强。 |
| 容量敏感 | 规模扩大可能影响执行、冲击成本或机会容量。 |
| 高换手 | 交易频率或组合周转显著高于同类。 |

#### `style_profile`

可多选，但必须能被持仓、因子、交易记录或访谈反复验证。

| 选项 | 标准 |
| --- | --- |
| 深度价值 | 长期偏低估值、逆向或安全边际。 |
| 均衡成长 | 成长与估值约束并重。 |
| GARP | 以合理价格买成长。 |
| 行业轮动 | 组合收益显著依赖行业切换。 |
| 短线交易 | 收益显著依赖较短周期交易。 |
| 高换手 | 组合周转高且是策略特征。 |
| 集中持仓 | 头部持仓或风险贡献集中。 |
| 分散持仓 | 风险贡献分散。 |
| 多因子 | 系统化使用多个因子/信号。 |
| 高频 | 日内或极短周期交易为核心。 |
| 中频 | 周到月级别交易为核心。 |
| 低频 | 季度以上持有或低交易频率。 |
| 指数增强 | 以基准为锚做增强。 |
| 信用下沉 | 信用风险暴露是收益的重要来源。 |
| 久期交易 | 久期和曲线判断是收益的重要来源。 |
| 趋势跟踪 | 趋势暴露是收益的重要来源。 |

#### `style_drift_risk`

| 选项 | 标准 |
| --- | --- |
| 低 | 历史暴露和沟通口径长期一致。 |
| 中 | 有阶段性偏离，但能解释并回归框架。 |
| 高 | 策略、仓位或风格频繁偏离原假设。 |
| 不清楚 | 数据或披露不足，无法判断。 |

### 4.5 People And Organization

判断团队是否能持续输出，而不是只看单个明星经理。

#### `manager_assessment`

可多选。

| 选项 | 标准 |
| --- | --- |
| 资深核心PM | 核心经理经验足，且历史可核验。 |
| 机构化团队 | 研究、交易、风控和运营职责清晰，不完全依赖个人。 |
| 关键人风险 | 结果高度依赖少数人，替代性弱。 |
| 团队纵深不足 | 覆盖、研究或交易资源明显不足。 |
| 近期人员变动 | 核心投研、风控或交易人员发生重要变化。 |
| 传承风险 | 接班安排、股权或激励不清晰。 |

#### `team_stability_assessment`

| 选项 | 标准 |
| --- | --- |
| 稳定 | 核心团队稳定，职责和激励清晰。 |
| 正常流动 | 有人员变化但不影响核心流程。 |
| 近期流失 | 核心人员近期离开或职责变化。 |
| 关键人依赖 | 单点依赖明显。 |
| 不清楚 | 缺少团队信息。 |

### 4.6 Risk Management

判断风险是否被主动预算、约束和复盘。

#### `risk_management_quality`

| 选项 | 标准 |
| --- | --- |
| 强 | 风险预算、止损/减仓、压力测试和复盘机制明确且执行一致。 |
| 合格 | 有常规风险控制，但压力期执行仍需观察。 |
| 被动 | 风险控制多为事后解释或净值压力后的被动调整。 |
| 弱 | 风险暴露、回撤或杠杆管理与策略承诺不匹配。 |
| 不清楚 | 缺少风控信息。 |

### 4.7 Capacity Liquidity And Terms

判断规模、底层流动性、基金条款和费用是否匹配策略。

#### `capacity_bucket`

| 选项 | 标准 |
| --- | --- |
| 可扩容 | 策略市场容量充足，规模增长不明显损害 alpha 或执行。 |
| 有容量约束 | 容量存在上限，但当前规模仍可接受。 |
| 接近容量 | 当前规模已经接近策略舒适区，需要限制新增。 |
| 规模过大 | 规模已明显影响机会、交易成本或风格稳定性。 |
| 不清楚 | 缺少规模和容量证据。 |

#### `liquidity_terms_fit`

| 选项 | 标准 |
| --- | --- |
| 匹配 | 赎回频率、锁定期和底层资产流动性匹配。 |
| 可接受错配 | 存在错配但有足够缓冲或透明机制。 |
| 明显错配 | 赎回条款与底层流动性不匹配，压力期风险较高。 |
| 特殊流动性风险 | 存在闸门、侧袋、集中赎回或难以估值资产风险。 |
| 未评估 | 尚未完成条款和流动性检查。 |

#### `fee_value_assessment`

| 选项 | 标准 |
| --- | --- |
| 费用合理 | 费用与 alpha、容量稀缺性、服务和条款相匹配。 |
| 偏贵但可接受 | 费用较高，但策略稀缺性或表现可部分解释。 |
| 费用不匹配 | 费用与可获得 beta/alpha 或透明度不匹配。 |
| 未评估 | 费用和条款尚未完成检查。 |

### 4.8 Governance And Alignment

判断管理人与持有人利益是否一致。

#### `alignment_quality`

| 选项 | 标准 |
| --- | --- |
| 强一致 | 管理人自有资金、长期激励、容量纪律和信息披露与持有人利益一致。 |
| 基本一致 | 未发现明显冲突，但激励或透明度仍需跟踪。 |
| 存在冲突 | 费用、渠道、规模扩张、关联交易或流动性安排存在冲突。 |
| 不清楚 | 信息不足，无法判断。 |

### 4.9 Historical Delivery

判断是否长期兑现了宣称能力。

#### `historical_delivery`

| 选项 | 标准 |
| --- | --- |
| 稳定兑现 | 跨周期和压力阶段均能解释并兑现核心能力。 |
| 环境依赖 | 在特定市场环境表现好，弱环境也可解释。 |
| 尚未验证 | 历史太短、经理变化或数据不足。 |
| 兑现失效 | 近期或长期表现与原始投资假设明显背离。 |

### 4.10 Portfolio Role

判断该基金在组合里的用途。

#### `portfolio_role`

可多选，但一般不超过两个。

| 选项 | 标准 |
| --- | --- |
| 核心配置 | 可长期承担组合核心风险预算。 |
| 卫星增强 | 用于增强收益或特定 alpha 暴露。 |
| 分散化工具 | 与现有组合相关性低，能改善风险结构。 |
| 防守/对冲 | 在压力期或特定风险场景下提供保护。 |
| 战术配置 | 更适合阶段性或环境驱动配置。 |
| 仅观察 | 暂不进入候选配置，只保留研究跟踪。 |

## 5. Notes 规则

Research notes 使用 `timeline_notes`：

- 每条 note 必须有 `note_date`。
- Overview chart 添加的 note 和 Research 页添加的 note 是同一份数据。
- `importance = high` 只用于会影响 rating、Research View 或标签选择的观察。
- `tags` 是 note 层面的临时主题，不等于 qualitative research tags。
- Research View、星级或标签发生变化时，必须新增一条 note 说明变化原因。

## 6. 变更触发器

出现以下情况时必须复核标签和 rating：

- 核心基金经理、投研负责人、交易或风控负责人变更
- 产品规模进入新量级，或新增/暂停申赎
- 单月、单季或压力期表现明显偏离同类和既定假设
- 持仓集中度、换手、行业/因子暴露明显变化
- 费用、锁定期、赎回条款、估值频率或披露频率变化
- 连续无法获得必要材料或访谈
- 投委会结论、组合角色或风险预算变化
