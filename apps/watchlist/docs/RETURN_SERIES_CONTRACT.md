# 收益序列与区间边界契约

## 1. 图表展示什么

Watchlist 主图把所选区间锚点归一为 `100` 的增长指数，不展示复权净值的绝对点位：

`growth_index(t) = level(t) / level(anchor) * 100`

图例、末值标签和 tooltip 继续展示累计收益百分比：

`cumulative_return_pct(t) = growth_index(t) - 100`

Canonical chart 的原始 level 与最新估值保留源数据经数值解析后的精度，不能提前按固定小数位四舍五入。区间交互及矩阵仍用这些 level 计算收益；小额现货价格尤其不能被舍入为零。小数位格式化仅用于界面标签，不写回计算序列。

- `total_return_nav`、`adjusted_close` 标记为 `Cumulative Total Return`。
- 指数的 `close`、`last` 只是供应商字段身份，不决定经济收益口径。必须读取 Registry 的
  `source_settings.return_semantics`：`total_return` 标记为 `Cumulative Total Return`，
  `price_return` 标记为 `Cumulative Price Return`；未声明或无法确认时保持 Unknown。
- 股票和 ETF 的未复权 `close`、`last` 只供报价观察与估值，不可作为内部收益的退路；即使声明 price return，未经拆股等行为处理的价格变化也不能代替收益。
- 原生 crypto 的 `close`、`last` 沿现货价格回报合同使用；不包含质押、借贷等收入。
- 基金只用有来源证据的 `total_return_nav` 推导内部收益；`official_nav` 保持单位净值，现金累计净值不变成再投资收益。

选择 benchmark 时，主序列与 benchmark 必须同时具有明确且相同的 `return_kind` 才能
计算 tracking error、information ratio、beta、capture ratio 等相对指标。Unknown 或口径
不一致时可以保留独立曲线，但相对指标必须 fail closed。

私募基金的窗口前复权因子会在比值中约去。因此，可靠的单位净值、窗口内现金累计披露和已确认行为足以计算窗口内收益；这不代表系统知道窗口前全部分红历史。

### 1.1 用户界面命名与内部 basis

`quote` 只作为跨资产的内部总称，不作为基金页面的具体指标名。Watchlist 按资产类型显示：

| 资产类型 | 最新估值字段 | 收益/图表字段 |
| --- | --- | --- |
| 公募、私募基金 | `Unit NAV / 单位净值`（`official_nav`） | `Cumulative NAV / 复权累计净值`（`total_return_nav`，含分红再投资） |
| 股票、ETF | `Latest Price / 最新价格`（valuation role 的 `close` 或 `last`） | 已确认分红再投资回报；显示价格可选择未复权、前复权、后复权，显示选择不进入分析 |
| 指数 | `Index Level / 指数点位`（valuation role 的 `close` 或 `last`） | 按 Registry 声明显示 `Price Index` 或 `Total Return Index` |
| 原生加密资产 | `Spot Price / 现货价格`（`close` 或 `last`） | `Cumulative Price Return`，不代表基金净值或包含质押、借贷等收益 |
| 混合资产 Watchlist | `Latest Value / 最新值` | 每行继续保留自身明确的 return semantics |

基金 Overview 的主数字固定为单位净值；其下方小字显示同一产品最新复权累计净值。切换图表
basis 不能改变主数字的估值口径。普通现金累计净值不进入这两个用户字段。

### 1.2 观察值、显示价格与收益分层

原始 OHLC、成交量、单位净值保持来源事实及其币种/单位，用于观察与估值。
`chart.price_series` 是 valuation basis 的原始全历史点；`chart.series` 保留所选 canonical 输入 level 的精度与尺度，不把指数点位或现货报价悄悄改为 100。
`chart.series` 是分析输入，与 `return_series` 和 summary 使用同一 `total_return` policy 候选顺序及收益资格。Registry 的 `chart` policy 可合法指向原始价格展示，但不控制该分析序列；原始价格仍由 `price_series` 和 OHLC 提供。不能因 `chart=close` 而丢失已有的可靠 TR，也不能把 raw close 当作分析收益的替代。

内部收益由共享 `investment_studio_instrument_core.return_series` 构建：`return_kind` 是 `total_return` 或 `price_return` 的经济口径；`return_measure='simple'` 是表示法。
每条 `intervals` 记录实际 `start_date`、终点 `date`、简单收益 `value` 和独立 `log_return`，两者均为小数。缺失的相邻区间保留 `status='unavailable'` 和原因，值为 `null`，不删除后跨接或填零。
对数收益只在 `1 + simple_return > 0` 时定义；不能将负价格、名义本金或衍生品合约价值作为通用收益分母。

`chart.return_series` 单独返回这些区间与派生 `wealth_points`；研究 read model 的 `research_returns.points` 同样是基准 100 的派生财富指数，metadata 标明 `level_kind='derived_wealth'`。
它不是可编辑、可交易的市场价格，不另建一份行情事实。证券公司行动未确认区间使 TR 分段；每段财富指数独立归一 100，canonical 点和财富点都带 `segment_id`，禁止跨段比值。

价格显示用乘法 TR 链派生，不使用富途含平移项的供应商前/后复权：
`display_ohlc(t) = raw_ohlc(t) * factor(t) / factor(anchor)`。
前复权锚定全历史最新有效点，后复权锚定全历史最早有效点，`price-bars.adjustment_anchors` 返回日期、因子及所属连续段的起止日；图表 start_date/limit 裁剪不能重选锚点；显式 end_date 同时是资料截止日，锚点不能使用之后才存在的因子。
`price-bars` 默认返回完整保留历史；显式 `limit` 才裁剪条数。详情页“全部”不使用隐含的最近 1,250 条上限。
仅在该锚点的已确认连续段、对应日期因子存在时显示复权 OHLC，成交量不随分红因子缩放。缺少证据只提供未复权观察，风险和绩效保持不可用。
这是一种明确的显示约定，前复权价格本身不成为独立 TR 定义；价格显示切换不能修改内部收益、估值或组合账本。

收益链的 `segment_id` 必须从 canonical chart 和 `/nav-series.rows` 一直传到基金及基准的显示与计算适配器；不能只保留日期和值。完整区间跨段时，区间收益、相对指标与路径风险都不可用。旧断点不永久封禁后来已确认的独立区间：近期 EWMA 与区间跌幅从最后确认段重新取样，仍遵守原有频率、样本量、缺口与新鲜度要求；缺少分段身份时不能猜测连续性。月度相对表现按相同实际起止日匹配，缺失月份不计为零，也不能延续更早的连续下跌月数。

基金回撤图固定读取内部复权累计净值，与矩阵和滚动风险同源。切换单位净值或复权累计净值的价格显示只改变观察图，不改变回撤；先在完整确认路径上计算回撤，再对展示点采样。风险复核中，完整历史回撤不可用不代表最近已确认的区间跌幅也不可用；两者分别验证；区间跌幅按各自实际观察窗口、波动初值按最近一年样本，逐对核对已保留的收益区间事实，窗口外的历史缺口不禁用完整近期窗口。缺少区间位置证据时不凭全历史缺口数量猜测连续性。行情过期或图表待重算仍不作为新的有效触发或恢复证据。

## 2. 边界定义

| 场景 | 请求起点 | 实际锚点 | 请求终点 | 实际终点 |
| --- | --- | --- | --- | --- |
| 自定义 2 日至 8 日 | 2 日 | 2 日或此前最近有效收盘 | 8 日 | 8 日或此前最近有效收盘 |
| MTD | 请求 `as_of_date` 所在月 1 日 | 严格早于月初的最近有效收盘 | 请求 `as_of_date` | 不晚于请求终点的最近有效收盘 |
| YTD | 请求 `as_of_date` 所在年 1 月 1 日 | 严格早于年初的最近有效收盘 | 请求 `as_of_date` | 不晚于请求终点的最近有效收盘 |
| 1D / 1W / 1M / 3M / 6M / 1Y | 请求 `as_of_date` 减对应日历跨度 | 不晚于请求起点的最近有效收盘 | 请求 `as_of_date` | 不晚于请求终点的最近有效收盘 |

因此，自定义 2 日至 8 日的收益是 `close(8) / close(2) - 1`，不是从 1 日收盘起算。MTD 和 YTD 则必须包含期初第一天的收益，所以使用期初前一有效收盘。

滚动窗口的请求起点始终由**请求的** `as_of_date` 推导。即使序列实际终点早于请求终点，也不得把请求起点随 stale 终点整体向前移动；否则所谓 1M 会悄悄变成另一个长度。1M / 3M / 6M / 1Y 按自然月/年回看，不用固定 30 / 90 / 180 / 365 日替代。

周频、节假日或停牌序列不得制造虚拟边界点。API 必须返回 `requested_start_date`、`anchor_date`、`requested_end_date` 和 `end_date`，让调用方看到请求边界与实际采用观测日期的差异。

Performance 页的自然期矩阵另有一条闭合规则：月度收益使用当月最后一个有效收盘/净值与上一个自然月最后一个有效收盘/净值相除；年度收益使用相邻自然年的最后一个有效收盘/净值。缺少整个月或整年时，不把更早期间的点跨接后冒充当前月/年收益。基于月度收益的滚动波动率、Beta 和连续下跌月数也只使用连续自然期，遇到缺口即重新开始/暂不发布该窗口。

矩阵单元格的 tooltip 会显示实际 `anchor_date` 与 `end_date`；因此当最新自然月/自然年尚未完整结束，或基金只提供月中/周频净值时，界面不会把实际采用的观察日伪装成月末/年末。

少于一个完整日历年的区间不得展示年化收益。达到首个日历周年后，年化指数按实际日历周年分数计算，不用 `365.25 / days` 把短历史外推成年化数字。

指数和原生加密资产详情页的 Metrics Matrix 只使用本页所选的 canonical series，各列沿用本节的区间锚点。区间收益取首尾点之比；年化收益使用上述实际日历周年分数；年化波动率、Sharpe 和 Sortino 使用区间内相邻观测收益及按实际观测密度推导的年化频率。Sharpe 的无风险利率和 Sortino 的最低可接受收益均为 0，Sortino 的 downside deviation 以全部期间为分母、非负期间记 0。Calmar 为年化收益除以最大回撤绝对值，因此不足一年或没有回撤时不发布。Recovery Days 从最大回撤谷底计至首次恢复该轮前高；尚未恢复时明确显示 `Unrecovered`。这两种详情页的主报价与价格图读取原始 valuation series；收益指标只取已确认的 analytical series，缺少该序列时不从价格图反推替代风险。

详情页 Overview 主图不提供固定窗口快捷按钮，只保留双端拖动范围条。拖动手柄绑定真实观测点，图例同时展示实际锚点和实际终点。标量 performance 字段覆盖 `1W / 1M / 3M / 6M / MTD / YTD / 1Y`；Sparkline 仍只物化 `1D / 1W / 1M / 1Y` 的有界展示路径。两类输出都使用本节边界规则，但字段集合不要求相同。

## 3. Watchlist 的逐 instrument as-of

股票／ETF 的行情、收益与图表候选点先按登记交易所日历排除已知休市日。原始供应商观察仍留在公共证据中，
不能以周末异常价格作为下一交易日的收益基点；剔除休市日不豁免任何真正缺失的交易日。
基金的 NAV 是披露观察，可合法落在非交易日；crypto 的 24/7 日线也保留周末。未知日历保持原有
未核验状态，不凭工作日推测补价或宣称完整。FMP 身份隔离会通过 canonical 报价的 `unavailable`
状态和源水位使旧物化失效，不能因旧日期仍新鲜而继续采用被撤销的价格。

- Watchlist 没有一个强制所有行共用的业务 `as_of_date`。每个 instrument 都以自己所选 calculation series 的最新有效观测日为终点，再独立回看 1W / 1M / 3M / 6M / MTD / YTD / 1Y。
- Screener 每行始终返回 `metric_as_of_date`。页级 `snapshot_metadata.as_of_date` 定义为当前结果中的最晚行终点，仅用于摘要，不得当成所有行的共同终点；同时返回 `as_of_date_min / as_of_date_max / has_mixed_as_of_dates / as_of_date_missing_count`。
- Screener 收益火花线只读取已确认的 analytical return series，每个展示窗口先核验完整收益区间。原始报价的显示选择不改变收益图；受影响窗口保留不可用原因并停止绘线，不能跨缺口归一化成一条看似完整的收益路径。
- 分组中的收益、波动率、回撤、Sharpe 和 peer 指标只有在所有有值行的 `metric_as_of_date` 相同时才展示等权横截面平均；终点混合或缺失时必须显示不可用。
- taxonomy peer 中位数及排名只纳入与目标 instrument **同一 snapshot as-of**、实际区间 Anchor / End、币种、观察频率和收益类型的固定区间收益。每个区间独立核验所有实际相邻收益区间；日度序列须有已确认交易日历，不能用自然日阈值宣称交易日完整；低频数据不得跨缺失的整周或整月。比较依据与 snapshot 一起保存，旧结果缺少依据、配置重算待完成或失败时不参与。窗口外缺口仍须披露，但不阻断独立完整窗口。不同存续期的 SI 年化收益、回撤、波动及风险调整比率只作资产自身描述，不生成同类中位数或排名。
- benchmark 比较采用双方共有的实际收盘日期作起止点，区间内部各自完整路径必须独立通过收益区间校验。基金自身独立指标仍用自己的 as-of；一旦展示 benchmark，矩阵中的基金值重算到最晚共同观测终点，SI 从最早共同观测起点开始。各自回撤、波动与风险指标保留这两个端点之间所有观察；相对风险统计才使用连续的共同 `(start_date, end_date)`。不能删除另一标的没有的观察日来抹去峰值或缺口，也不得把基金周五收盘与 benchmark 周四收盘当作同一期相减。比较矩阵每列显示实际 Anchor / End；不足共同窗口或窗口观察不完整时显示不可用，不回退到资产独立最新值。说明列出双方实际披露频率、共同终点与独立指标/月表终点。

## 4. 频率、缺点与风险

- 保留来源合同与实际观察频率，不做降采样、插值或补零。收益区间始终保留真实起止日；明确的 weekly/monthly/event-driven 数据不标成 daily，也不套用固定日度风险观察窗口。声明为 daily 的稀疏数据仍按 daily 合同检测缺口，不能把缺点自动解释为低频合同。
- daily 数据若配置 `market_calendar`，内部缺点按该交易所真实 session 检测，春节、周末等休市不算缺失；未配置或日历不可解析时，profile 明确为 `schedule_unverified`／`gap_status=unverified`，`gap_count=null`；只保留真实最大观测间隔描述，不以自然日阈值推断缺口或声称对齐。正式绩效、路径风险与比较窗口在日历未确认时不可用。
- 尾部新鲜度按该 instrument 自己的 market calendar 和 `release_lag_days` 判断，不拿 Watchlist 中其他 instrument 的最新日期做基准。有可用日历时，`release_lag_days` 按该日历的交易日数量延后；24/7 日历的交易日即 UTC 自然日。未显式声明滞后的邮箱私募采用一个交易日，显式配置优先。当日盘中不要求尚未完成的观察，盘后则按共享交易所完整收盘时钟纳入当日（港股含收市竞价，数字资产按完整 UTC 日）。无可用日历时新鲜度不可核实，不以自然日宽限判为 fresh；低频来源不套用日频发布预期，明确事件驱动合同独立处理。
- canonical 固定窗口绩效、年度/SI收益和基金详情页矩阵、月表、收益图、回撤图使用同一实际窗口完整性口径。缺失观察、收益区间证据或未确认分段时受影响窗口不可用；不把纯端点变化改名作为正式绩效的备用值，原始报价仍保留。基准独立核验完整路径，比较不能通过删点交集修复缺失。窗口外历史问题保留披露，近期独立完整窗口可用；滚动风险逐窗口核验，不因全历史旧缺口永久关闭。
- 每次重建图表及其窗口元数据时，performance / risk 快照从同一次捕获的收益样本同步生成或清除，包括持仓触发的 exposure 重算。不得把旧标量配上新窗口、收益图或物化版本。
- 最大回撤、当前回撤、波动率、downside deviation、Sharpe、Sortino 等路径指标在存在预期观测缺失时 fail closed。downside deviation 以全部期间为分母，非负期间的 downside 为 0；样本有效且全为非负收益时发布 0，Sortino 因分母为零仍不发布。Sharpe/Sortino 当前风险自由利率为 0。

### 4.1 原生加密资产与 UTC 日线

- `crypto` 是原生资产类型，与股票、ETF 和指数分开登记。当前维护的 BTC/USD 序列以美元/枚 BTC 报价，`return_semantics=price_return`；不把 BTC/USD 与 BTC/USDT 混接，也不把现货包装为 ETF 或指数。
- `market_calendar=24/7`，每个 UTC 自然日均应有观察值，包括周末。采集投影只接受早于当前 UTC 日期的已完成日线；当日未完成价格不进入这条收盘研究序列。新鲜度以 UTC 前一日为预期最新日，不能套用纽约股票交易日。
- 连续日频风险的年化观察数为 `365.25`；通用风险计算仍按 `观察间隔数 / 实际跨度天数 × 365.25` 推导频率。缺失任何预期 UTC 日线即标记缺口，不把周末当休市，也不以降低年化观察数掩盖缺失。收益年化仍使用第 2 节的完整日历周年规则。
- Metrics Matrix 按各自窗口逐日验证完整性。历史早期缺口继续使 SI 的路径风险不可用，但不使缺口之后完整的 1W/1M 等窗口失效；没有补点或插值。后端全历史风险仍保留原来的覆盖不足状态。
- BTC/USD 当前点由共享 `market_series_daily` 投影，canonical provider 标识来源序列，日期标识观察日；原始版本、采集批次和按获知时间查询的历史版本保留在 numeric 存储。canonical 当前点会随来源修订更新，并未逐点绑定不可变的原始批次；不能单靠当前点重建历史 PIT。可复核的研究须使用当时冻结的研究输入及原始来源版本。
- Watchlist 的登记、行情与研究支持不授予 Portfolio 交易能力；当前 Portfolio 的交易选项及录入校验排除 `crypto`。

数据年龄是阅读时钟的日历日差，不是上次物化时冻结的天数。详情新鲜度提示始终显示实际观察日、当前参考日与 UTC 时区，并在跨 UTC 日后更新年龄；交易所 session 与披露滞后仍决定业务上的 stale 状态，日历年龄不替代该判定。

## 5. 私募基金断段规则

- `window_normalized_anchor` 只表示观测窗口起点归一为因子 `1`；它不声称累计现金差额为零。
- 窗口内疑似现金分红但尚未确认时，复权收益序列在事件前停止，并标记 `partial`。
- 管理员确认分红及再投资净值后，投影、Watchlist read model 和 Portfolio 相关任务按统一队列重算。
- 不得用“单位净值加历史现金分红”的现金累计值冒充再投资复权累计净值。

## 7. 研究比较与跌幅复核线

研究对话的比较工具先独立核验各标的请求区间的完整收益区间，再对齐共同实际观察日，不前向填充。缺失交易日、缺少区间证据或跨未确认收益段时，该标的的受影响比较不可用，不能用日期交集抹去缺口。首尾收益和相关性使用列示的共同区间；最大回撤保留共同首尾之间各自完整观察路径，不删除另一标的没有的峰值。合法不同日历或披露频率的端点对齐须披露各自路径观察数与对齐观察数，不冒充完整日频相关性或年化指标。样本日期、币种、实际收益口径和剔除原因随结果返回。不同币种不直接混算；未知经济口径不参与。明确 PR/TR 混合研究比较保留各自标识并披露可比性限制，不把 PR 冒称 TR。没有共同基准时不生成超额收益，观察列表也不代表全市场排名。

请求窗口的首部和尾部同样属于覆盖责任，不能因现存点较短而先缩小窗口再验证。`research_returns.observation_schedule`
保留生成该快照时已有的日历、频率、发布滞后、来源方式和资产类型；比较按本轮冻结的 `cutoff` 复用真实闭市及发布时钟，
不从当前 Registry 补入后来的配置。日频请求内所有已经到期的 session 均须有实际观察，缺失日期随 `window_coverage` 返回；
休市不算缺日，半日市与港股收市竞价使用实际截止时刻，尚未收盘或未到披露期限的日期明确披露。观察已提前取得且市场 session
确已完成时可使用；尚未完成 session 的点不可使用。当前行情过期不否决一个已完整的历史请求窗口。

仅声明周频或月频、没有确切发布安排时，请求起止日均须有实际观察，同时核验完整自然期缺失；缺少实际端点不可缩短窗口出数。
合格低频与事件驱动比较标记 `observed_endpoints_only`，不推定固定披露日。月度收益另核验自然月末端点；日频按真实交易日历确定月末，
无确切发布日历的低频来源须有实际自然月末观察。上一自然月的月末观察尚未到披露期限时仍不可给出完整月收益，不能拿更早值代替；
只有冻结时刻所在月标为月内截至观察日，过期的最后观察月不冒充当前月。月度超额收益与连续负月计数同样受此覆盖限制。
配置基准和同类的风险证据先核验双方较晚的实际终点，
不能先取日期交集丢掉其中一方缺失的最后一个交易日；双方都较旧时保留原 `freshness` 和实际样本终点，只作历史描述。
若当前业绩快照生成、来源更新或观察日期晚于冻结时刻，整份受影响业绩输入不可用；不能裁掉较晚日期，把当前修订值冒充当时可得版本。

标的风险的近 1 日、1 周、1 月、1 季分别使用最近 1、5、21、63 个日频观察间隔；`24/7` 加密资产使用 1、7、30、90 个 UTC 日频间隔。这些是跌幅复核窗口，与第 2 节按自然月计算的 1M/3M 业绩窗口分别定义。只有已就绪、无未确认断点且无缺口的日频序列才参与；不足窗口则显示不可用。复核线首次使用最多 252 个对数收益、至少 63 个收益的样本标准差 `sigma` 校准；`24/7` 序列改为最多 365、至少 90 个收益。按 `100 × (1 − exp(−k × sigma × sqrt(n)))` 得到正的跌幅容忍值。四个窗口的 `k` 为 3、2.5、2、1.5，最低容忍值为 0.5%、1%、2%、3%，向上取整到 0.5 个百分点。这些是初始复核规则，不是经验分位数或预测损失概率。

每个跌幅窗口及首次校准样本使用与正式绩效相同的收益区间证据；没有保留的区间或没有已确认交易日历时，不以 `gap_count=0` 推定连续。旧缺口在实际样本之外时不阻断当前完整窗口，仍保留全历史缺口披露。

研究中的 EWMA 价格波动另按资产日历定义：股票、ETF、指数使用 21 个交易观察的半衰期，最多 252、至少 63 个连续实际收益并按 252 年化；原生加密资产使用 30 个 UTC 日的半衰期，最多 365、至少 90 个连续实际收益并按 365.25 年化。两者只采用最后一个缺口之后的连续样本，指数权重归一并扣除加权均值；不得将基金净值套入该价格波动定义。

规则和校准样本保存后不随日常波动自动抬升，可逐窗口人工修改或关闭。自动观察由现有 recalc 流程更新；GET 只读，不因打开页面生成事项。资料不足不能证明风险恢复；触发解除与人工跟进状态分别保留。实现和验证见 [price_risk.py](../backend/watchlist_app/services/price_risk.py) 与 [test_price_risk.py](../backend/tests/test_price_risk.py)。

### 7.1 投资研究的固定量化观察与事件反应

`research_observations` 读取研究截止时间之前生成的 canonical 图表快照及已留存共享数值，不发起供应商刷新。
输出沿用 `computed_metric`、`figure_source_ids`、留存表格与来源读取合同；页面不重算指标。每份证据保留输入快照、
源记录、方法版本、实际日期及覆盖限制。业务变化比较采用数值、样本与方法，重新生成的 source ID 不是新变化。

股票相对表现的 `1W / 1M` 沿用第 2 节日历窗口，并在双方共同实际日期上选取锚点和终点；只有币种与收益口径明确且
相同时才给出收益差（百分点）。未配置基准、币种未知或复权不一致时不生成相对值。成交量变化为最近两个相邻完整交易日
成交股数的百分比变化，前值为零时保留原值而不输出无穷百分比。EWMA 复用本节既有实现；当前回撤复用 canonical 实现且
须先确认完整路径。未完成日线不进入这些观察，也不补点或把缺失值记为零。

固定观察的方法版本由 `research_observations.OBSERVATION_METHOD_VERSION` 维护，分别保存研究资料截点（精确时刻及市场所在地日期）、最新完整价格日及持仓披露日期。
留存资料的 `available_at` 不得晚于研究截点，持仓日期也不得晚于该截点的市场日期；已经获知的周末持仓可以描述此前完整交易日
的价格表现，不能因为持仓日期晚于最后价格日而丢弃。价格窗口仍止于实际完整价格日，不引入研究截点之后的价格或资料。
旧冻结来源保留原方法与结果，新计算另建来源，不改写历史。

ETF Top 10 是“已披露股票篮子”的实际权重排序，不足十项不补齐；权重缺失时明确排序不完整。成员必须有已确认的股票分类、
唯一持仓键及证券身份。每个成员保留币种和收益的实际区间，不作历史持仓或收益贡献归因，也不据此声称整个 ETF 非杠杆。
现金、货币基金、期货等头寸单独保留，不计入股票广度、排序与相关性；期货披露权重不等于名义敞口，未取得衍生敞口时明确其未知。
供应商 `holdings_count` 可能只统计股票，与总持仓行数分别保留；实际分类后的股票数是当前披露股票篮子的分母，不用前者猜测产品结构。
股票权重沿用披露分母，不重新归一化；Top 10 显示披露权重合计而非整个 ETF 的风险集中度。未分类头寸、负权重/负份额、
权重缺失及实质超过 100% 的合计不生成股票聚合指标。针对留存 FMP 披露的八位小数百分比精度，合计只允许每行最多半个
`0.00000001` 百分点的舍入尾差；更细精度使用更小界限，原权重不截断、不改写，不能借此吞掉真实超额或负头寸。
第一版共享读取使用已有 FMP 身份和数据；未取得指数成分或其他市场成分时不推测。

ETF 自身也显示相同口径的 EWMA 波动和当前回撤。Top 10 相关性按当前披露权重选取最多十个股票成员，在最近
63 个实际交易日的同币种、同收益口径简单收益上计算 Pearson 两两相关系数，再对证券对等权平均；保留共同起止日、
成员与完整相关表。需要至少两个成员及全部所选成员的连续 64 个价格点；不对缺失填充，不以两两不同样本拼接。
恒定收益序列的相关系数无定义。当前权重只选择篮子，不为相关系数加权，也不代表历史持仓或实际风险贡献。

内部广度为有效成员最新价格严格高于最近 50 个完整交易观察均价的比例，采用同一实际交易日历且不跨缺失 session。
报告实际已披露股票成员数、有效成员数及可确认权重覆盖；覆盖不足标记 partial。只有 Top 10 行情时不发布整个已披露股票篮子的广度。
前后广度变化只使用同时具有本次与前次有效窗口的共同成员，并保留共同成员数量及当前共同样本比例；当前持仓的历史
价格比较不声称重建了以前的真实持仓。

事件反应使用真实交易日历上的精确完整收盘端点。仅知道事件日期或已确认盘后发生时，从事件日收盘观察后续完整交易日；
日期精度的事件明确说明可能遗漏日内反应，不虚构盘前盘后时刻。已核实盘前发生才允许用前一交易日收盘到事件日收盘。
非交易日事件从此前收盘到后续交易日收盘。窗口未结束返回 pending（尚待观察），窗口结束但端点缺失返回 unavailable；
基准日期、币种或收益口径不匹配时仅保留标的结果并标记 partial。数值是窗口表现，不是事件因果或公开市场共识的证明。

## 6. 单资产日度尾部风险

`GET /api/instruments/{id}/tail-risk` 从 canonical chart 的 `return_series.intervals` 只读派生，不增加一份行情或风险快照。单资产、不加杠杆的多头损失为普通收益率的相反数，以报价币种计量；不代表持仓金额 VaR，也不包含组合汇率或仓位。股票、ETF、基金要求确认的分红再投收益；指数使用明确的 PR／TR，加密现货使用价格收益。显示复权或 log_return 不进入该计算。

置信度 95%／99%，回看 365／1095／1825 天。根据来源交易日历及披露滞后确定应到日期（邮箱私募未指定时沿用一交易日规则），区间保留真实请求边界和实际样本边界。只接纳两个端点为相邻交易日且状态完整的收益，不填补或缩放。实际样本内部或尾部缺失应有区间、出现不可用区间或跨多交易日区间时，VaR／ES 不可用，不删除后继续估计；返回精确缺失起止日期。完整回看覆盖、前段／内部／尾段缺口分别披露。新资产或来源历史较短的前段缺少不声称成立前漏净值。末端不可用收益不能冒充最新有效样本。

VaR 使用逆经验分布分位数，ES 按恰好 `N*(1-confidence)` 的尾部概率质量积分，边界情景使用分数权重；并列值不通过 `loss >= VaR` 改变尾部概率。尾部不足一个等效情景时按产品规则不展示，超过一个不证明估计充分。该纯统计定义由 instrument-core 与 Portfolio 共用；两边经济敞口、样本、FX 及权限各自负责。

仅因历史较短而缺少样本前段时，可按披露的实际起止日标为 partial 计算；这不证明回看上限已完整覆盖，也不声称成立前缺净值。内部／尾部缺口不发布 VaR／ES，不跨经济断点构造收益。当日已收盘按共享交易所时钟判断，港股包括最迟结束的收市竞价；全天数字资产仍以完整 UTC 日为界。风险事项仍由原 RiskCase 管理，风险页和抽屉访问同一记录。
