# 投资研究系统

本文是研究页面、多 agent 协作、研究助手和风险转介的当前合同。服务及权限见 [Architecture](ARCHITECTURE.md)，接口见 [Watchlist 数据模型](../apps/watchlist/docs/DATA_MODEL_AND_API.md)，数值与信息时钟见 [Market Data Pipeline](MARKET_DATA_PIPELINE.md)。

## 目的与范围

投资研究帮助投资经理形成有依据的判断，突出影响决策的事实、分歧和条件。新闻条数、主题数量和模型调用次数不是研究质量。研究建议不直接改变 PM 观点、目标配置或交易。

完整研究面向公司股票、股票 ETF、行业指数和股票公募。股票公募须有已登记的权益分类；ETF、指数的底层敞口须根据实际披露核实，明确非权益的产品不进入本轮自动研究。名称、分类或平滑净值不能证明持仓、杠杆或策略。私募策略、加密资产及其他非权益资产暂不开展此套研究，但确定性数据、风险监测、人工资料和研究助手继续可用。

## 统一投资研究工作面

投资研究使用四个平级入口，避免把同一内容在多个区域重复展开。

| 部分 | 默认呈现 | 按需展开 |
| --- | --- | --- |
| 总览 | 增持、减持、维持或无法判断；核心依据、机会、重要风险及改判条件 | 原始依据、详细分析和研究版本 |
| 标的动态 | 新闻与公告、市场观点、财报与业绩会、会议纪要的日期轴；重要性、影响方向、跟进状态 | 事实和观点的区别、影响机制、下一观察和来源 |
| 重要研究主题 | 具体催化剂、当前认识、最新实质变化和下一验证 | 主题时间线、人工记录、关联事件和证据 |
| 量化指标 | 价格收益历史、基本面、分析师预期、估值、量价指标及适用的特别数据 | 同口径历史、完整数值、方法、来源与覆盖限制 |

“标的动态”是标的在外部世界发生的事情，不收研究结论修订、主题编辑、运行日志或例行检查。后台使用 `event_category=news|opinion|earnings|meeting|other` 分类；`information_type=fact|opinion|rumor` 单独表达证据性质。内部研究版本仍可在原记录中追溯。

总览的 `investment_view` 是唯一当前 AI 判断；`decision_brief` 是同一判断的简明建议，绑定该观点版本。无有效版本时不沿用失效摘要。机会和风险可以同时存在，不强制目标价、概率或仓位。观点缺失、资料不足、暂无实质变化、运行失败分别显示，不能把未知显示成“中性”或“无风险”。

量化指标的确定性图表和数据不依赖 AI 是否启用，数据日期与分析日期分别显示。市场观察、经营财务分析和未分类计算保留各自 `observation_domain`；`market-quantitative` 模块只引用市场类图表，基本面模块可以在量化指标内呈现其自身数据。页面不从标题猜测类型、不补缺失值、不重算原件。展示价格口径与总收益口径分开标明。

每个部分都有可编辑的研究 skill，保存在 `mandate.section_skills` 的 `overview/recent_updates/themes/quantitative` 中。全标的用户指导保存为 `guidance`。编辑使用 `expected_revision`，在标的锁内核对版本；冲突返回 409。AI 可以提出方法建议，不能覆盖人工指导。不存在按股票代码注入的隐藏研究重点。

## 多 agent 分工

一个正式标的研究运行固定同一信息范围和发布所有者，由主研究员按实际问题决定直接研究或委派。动态、主题、量化是可复用的专业分工，不是每轮必须依次执行的三个阶段。相互独立的委派可并行；主题负责人还可把独立主题拆分一层。四个页面分区不随执行任务数量改变。

| 会话 | 专属输入 | 主要工具及结果 |
| --- | --- | --- |
| 标的动态专员 | 持续事件、本轮受影响事件、资料检索起点及覆盖缺口 | 资讯检索、原文读取；事件提案、重要风险与限制 |
| 主题专员 | 活跃主题、其具体问题、本轮相关事件及可升级的动态 | 定向核查、主题和原件读取；主题提案、事实与分析 |
| 量化专员 | 可用数值目录、前次量化认识、历史比较及数据缺口 | 已存行情、财报、预期、共同样本与隔离计算；重要变化与风险 |
| 主研究员 | 本轮变化、上次有效判断、当前 PM 观点及已完成子任务 | 决定分工、直接处理简单问题、整理证据和分歧，提交统一研究草稿 |
| 独立事实核证 | 绑定的最终草稿、实际子任务的简明发现与限制、相关旧判断及原始证据 | 核对事实、引用、信息时点和计算口径；对照原件处理专员与草稿之间的矛盾，不联网补造依据或直接发布 |

基本身份、用户指导和信息截止是公共部分，研究问题、skill、预载材料和工具列表按角色与任务区分。Harness 原生 fresh spawn 创建独立子会话，不复制父聊天。`read_assigned_context` 由宿主绑定真实子会话身份，只提供分配的标的、主题及直属子任务；主研究员读取全轮任务目录。需要核查时可按明确问题读取共享原件；另一专员的分析不能充当独立事实来源。

`delegate_research` 调用原生子代理，子代理返回符合本角色结构的提案，可信宿主将其保存到同一运行的 `research_tasks`。任务身份、父子关系和目标由宿主与服务验证，不采用模型自报身份。任务结果绑定原 `input_snapshot_cutoff`，支持路径和分页读取；相同范围及问题的已完成任务可复用。子代理不能发布或修改 PM 观点。仍有运行中任务时主草稿不得提交；失败任务必须保留具体限制。没有委派不代表没有覆盖责任，本轮受影响事项仍须回应。

专员提案在传输、保存和综合交接中保留原有字段及省略语义，不把未提交字段补成空值。总览保留已校验的事件、主题结构和完整来源编号，仅协调具体证据冲突；核查量化依据时遵循留存结果给出的读取入口，包括同一运行内的比较计算。

最终研究仍经独立核证和统一发布事务，校验当前身份、标的范围、来源归属、信息时点及底稿版本。草稿被工具接受不等于已经发布，格式通过不等于事实成立。各阶段保留实际模型用量、状态和来源，供人工复盘。

## 增量监测与冻结工作集

日常检查以最后成功的覆盖位置为起点。`research_monitor_state` 分别持有扫描位置、待处理变化、已尝试版本和成功应用位置；失败或暂停不消费待处理资料。只有发布成功才确认本轮实际处理的变化，期间新到资料继续保留。无变化可以保留原判断，不为了日期改变而重新写文章。

运行的 `research_working_sets` 冻结基线版本、持续跟踪事件、重要活跃主题、受影响集合、触发原因及直接依赖来源。默认不预载已结束事项、全部历史、旧工具输出或每次研究修订。必需复核的事件和主题须有明确回执；未选中项保留原判断及日期，不能冒充本轮已复核。
初始化且绑定底稿尚无有效观点时，正式提交须包含非空 `investment_view.direction`；可以明确无法判断、有限覆盖或 `not_established`，不能只交摘要或 `research=null`。已有有效观点的日常检查和局部修订仍可省略研究正文。

档案中上次已完成运行的工作集和复核议程只是参考，不会扩大研究助手本次问题的范围。对话只提交相关的实际变化；内部检查、回执和编辑说明不写入标的动态正文。催化剂只确定月份或尚无日期时，具体日程留空，已知时间范围写在说明中，不以月初日期代填。

标题、摘要、日期和来源目录优先。只有与当前论点有关时才读原文或历史确切版本。目录命中、压缩摘要和工具可用性都不是已读原文的证据。更正、撤回、晚到材料保留实际版本和日期；不得把采集日写成发生日，也不能用当前原文填回过去的认知。

资料不足须指出缺失的内容及受限判断。FMP 财报、预期和持仓沿用既有数据能力；当前没有专用 FMP 业绩会转录采集器，相关纪要可从共享文本或有依据的发行人公开原文取得，不因供应商提供该产品就声称本轮已覆盖。基金和指数的成分分析必须保留真实持仓日、权重及覆盖，不能拿公司 EPS 冒充 ETF EPS。

研究可主动补充外部资料：先查共享目录，再围绕具体缺口搜索或读取已知公开原文。通用搜索由已授权的 Watchlist API 直连 Tavily，单次 basic/general 查询最多十条线索、每条一段供应商摘要，不请求生成答案或原文提取，也不自动重试、切换供应商。密钥只在 API 侧；网络请求前后校验当前 run/attempt 和权限，独立核证及风控不能新增外部搜索。查询仅含公开名称和问题，不发送持仓、账户、私有文件或整段研究上下文。搜索摘要、排名和供应商日期不是已读原件或已核证时钟，外文及其他外部内容都不是指令。结果和错误沿本轮 `web_evidence` 保存；用返回的 `search_id`、相同 query 及 `next_offset/deferred.path` 续读原结果，不再次联网。未配置密钥明确返回 `not_configured`；真实空结果与取得失败分别保留，不能推断没有重大事实。已知 URL 抓取支持 HTML 与 PDF 文字层，当前每份最多保存 12,000 字符，截断、无文字层和访问失败保留为覆盖限制，不能据此声称读完年报。

`list_wind_tools` 按需发现一个 Wind 领域的实际只读工具及参数；`query_wind_data` 查询公开实体、字段和日期，后端持有私有授权。开放新闻公告、基金、股票、指数和宏观领域，不挂载全量原生工具或通用分析服务。主研究员、专员及主题子任务共享本轮留存原件；已完成的相同请求复用，后续读取按原 `source_id` 分页，不再次消耗查询额度。同时发出的重复请求仍可能分别计费，主研究员应划分互不重复的取数任务。认证、额度及数据缺口明确返回，不通过改端点或扩大问题掩盖。研究不自动批量扫市场，供应商实际额度另按账户约束管理。

Wind 响应复用已有数值原件容器，以 `analysis_kind=provider_snapshot`、`operation=provider_read` 和 `no_calculation=true` 明确为供应商原件。完整响应、请求条件与实际取得时间保留，原单位、量级、报告期及文档发布日期不重解释；新闻公告 RAG 的片段不冒充全文。原件可作为 Python 的精确输入，生成图表仍须实际计算。网页和数据补查不修改原行情／账户快照，后来取得资料不回填为过去已知；独立事实核证只读留存依据，不调用外部服务。

## 跟踪生命周期

重要性表达是否值得投资经理花时间阅读；影响方向、可信度、风险程度和紧迫性分别判断。事件沿用 1–5 注意优先级：3–5 进入主时间线，1–2 作为背景。评分不是收益概率或交易评级。默认日期轴展示最近七个自然日；持续跟进与历史有独立入口，这个展示窗口不限制后台增量采集。

事件使用 `follow_up=watch|none|resolved`。持续跟进要有具体下一观察；一次性信息可以不继续跟踪。明确开始跟进时默认复核期限为 30 天，重复转载和检查不续期。到期表示需要复核，不自动证明问题解决。PM 固定、明确未来观察节点及重大未结风险保留原安排。停止跟进、关闭主题或事件出窗都不能解除风险。

重要研究主题聚焦可研究、可跟踪、影响重要且通常六个月内可能影响价格的具体催化剂。创建须有证据起点、传导机制、未决问题、下一验证及失效条件；“AI 增长”“估值”“现金流”等分析目录本身不是主题。不凑数量，活跃主题上限沿用十个。

主题可从标的动态升级或人工建立，有自己的事实与分析时间线。用户可以添加人工记录和删除主题；删除须核对当前 revision，在锁内清除相关研究引用，不删事件原事实、PM 观点或风险事项。普通暂停/关闭保留主题历史；人工固定、暂停或关闭的生命周期不能由 AI 擅自恢复。人工记录保留作者、日期和来源。

## 数据、判断与写入所有权

| 对象 | 所有者及边界 |
| --- | --- |
| 价格、NAV、FX、财报和公告原件 | 数据系统；保留时点、来源及修订 |
| 账户、交易、合约及已保存配置 | Portfolio；研究没有交易或账本写权限 |
| 量化证据 | 确定性工具；保存实际输入、单位、样本、方法和结果 |
| AI 投资判断、事件分析与主题 | Watchlist；经核证、来源检查和版本锁发布 |
| 人工观点、主题记录与 skill | 原作者；AI 不能冒充作者或覆盖其原意 |
| 风险判断 | 独立风控路径；研究上报不等于风险已经确认 |

价格变化、相关性和收益结果不证明因果、预期充分定价或决策正确。持仓权重表示敞口，不能仅比较受益和受损持仓的权重就断言利润或估值影响能否抵消；净影响判断需要同一情景下可比较的冲击、传导与敏感性假设，缺失时保留条件性机制和未决结论。分析师预期比较必须保持公司、预测期间、指标和币种一致；期间滚动或覆盖变化不能当作预期修订。缺失持仓权重、总收益或交易日不能用零值或估计填补。

量化先用现有计算；必要时在隔离 Python 环境中分析本轮已留存输入，保留问题、代码、假设、来源和结果。沙箱没有业务数据库、凭据、网络或任意宿主文件权限；隔离不可用时明确失败，不降级宿主执行。探索性统计不是正式回测，研究建议不是交易授权。详见[量化执行环境](../infra/research-quant/README.md)和[收益序列合同](../apps/watchlist/docs/RETURN_SERIES_CONTRACT.md)。

## 研究助手与组合

各部分、事件、主题和研究记录可带当前引用打开研究助手。对话是私人的，默认回答不会发布团队研究。保存 PM 观点、创建或修改主题须有用户当前明确指令；保留作者、引用和版本。团队发布另经明确授权、独立核证及正式发布校验。组合绑定对话不能把私人持仓资料写入团队标的研究。

组合助手通过 `read_portfolio_holdings` 读取本轮冻结持仓、账户和风险依据，保留估值日期、币种、现金已结算/待结算及覆盖缺口。同一运行按 `source_id` 分页复用原证据，不续页时查询新持仓。账户现金不是证券净值或券商购买力，缺失余额不等于零。

`calculate_portfolio_allocation` 调用 Portfolio 已有配置求解器，使用已保存分类、目标、约束和生产风险口径；返回可分页的 `inputs/solution` 来源。没有已保存目标时明确要求先设置。计算前后检查账本、行情、目标及优化设置的一致性，期间变化使结果失效。它不修改目标、不生成交易、不运行历史回测。重复读取同一来源不重复求解。

## 风险转介与首页提醒

专员将有具体损失机制和证据的重要或严重风险交给总览；统一研究发布将风险线索交给既有风控路径。风控结合真实标的数值、VaR/ES、波动及回撤等适用指标判断。Portfolio 在实际持仓和约束下评估成员风险与组合风险；私人组合评估不能代替团队标的风险判断。

研究跟进状态与风险权威状态分开。新版本待复核时保留 `last_assessed_snapshot` 中已确认且未解除的风险，`pending_revision` 不借旧确认给新正文背书。来源撤回须提示依据失效，例行检查、关闭主题和无新消息不能清除已确认风险。团队风控必须对本轮绑定的待复核上报留下结论及原因；缺少回执不能视为完成。

首页仅展示重大有效风险，以及有原文依据、明确紧迫决策条件的重大待核实事项。普通波动、资料缺口、模型失败和纯机会不占入口。默认最多三个短链接，可继续读取完整范围；空列表不表示全部资产无风险。来源团队及权限先过滤再分页，首页不读取私人对话或私有组合材料。

价格复核线是观察窗口的损失幅度阈值，不是 VaR、止损指令或可消耗预算。带符号收益与正的损失限额分别保留；正收益和零触发不能证明低风险。详细金融口径由原风险服务和计算合同持有。

## 每轮检查与长期连续性

研究助手、标的研究和风控持久入队，独立 `research-worker` 执行；API 不持有模型进程。队列保存原主体、run、attempt、执行 owner、心跳和租约。云端默认同时执行一轮研究，其原生子任务共享该轮执行所有者，不建立第二套队列。模型请求并发默认三路，等待子任务的父代理不占请求槽；增加 worker 并发时须同时核算实际模型并发和主机容量。

主研究及其子任务树、独立核证分别有 30 分钟截止；阶段切换重新验证原权限并签发阶段委托。子代理通过受限研究工具读取证据，不能取得数据库、交易或人工业务写入能力。委托不超过父身份有效期，撤权或过期阻止继续执行和发布。正常终止、暂停或超时清理整棵原生任务树及进程组。

暂时性故障按原运行、输入和主体最多三次总尝试，冷却至少 60 秒、300 秒。确定性协议或资料错误保留失败，修复后才恢复；未形成有效提交的生成超时不自动重新付费。已经受理的草稿、专员结果及核证检查点在原输入范围内复用；已完成发布不重复。风控新会话重新读取必需资料，不能把旧会话阅读回执当成本轮已读。

核证工具原子保存有效收据后，原生运行在下一模型步骤前结束，不再为确认收据调用模型。应用仍校验收据、保存绑定检查点并执行发布检查；模型进程结束本身不代表研究已发布。

生成、核证和发布各自留痕。普通助手只在明确授权且有受理草稿时核证共享成果；核证失败保留私人答复，并明确发布未完成。草稿因核证中断或发布校验失败需要重新核证时，显式 `recheck_review=True` 沿同一草稿和截止重审，不重造证据。同发起人通过既有手动重审入口可附 `review_guidance`，只保存为本次重审的待核疑点，不改原问题、草稿、截止或来源；该提示不是事实、证据或发布批准，核证员仍须独立读取原件判断。

工具在 HTTP 层分页后才送 MCP；单页不超过既有 48 KB 上限。`next_offset` 和 `deferred.path` 续读同一来源、版本及权限边界，不截短计算样本或原文。独立计算原件使用 `research_run_evidence`，运行轮询只读轻量投影，避免不断加载完整历史。页面目录、引用和实际原件阅读分别记录。

主研究员核对本轮结论依赖的旧论点；前提修正时，将受影响的当前模块、主题、观点和简报一并作为局部更新提出。独立核证负责原文支持、财务推理、时点及跨字段一致性；已发布或曾通过核证不代表事实仍成立。审核发现草稿范围外的旧错误时，记录具体位置和证据缺口，拒绝仍依赖该错误的新判断，不能越过局部更新边界改写旧字段，也不能把驳回修改当作旧内容已修好。代码负责来源、权限、单位、引用和版本等确定性合同，不为每一种投资推断逐条添加特例。

核证须获得完整草稿、必要覆盖、相关旧判断及支撑论点的原文片段。来源目录提供 `evidence_reads` 精确正文入口与时钟，优先直读论点所需原件，只补充必要元信息；相互独立的读取可以同批发起。目录、入口本身或未交付延后内容不是已读证据。核证工具 schema 与实际校验共用同一绑定包，提供绑定对象的提交结构示例；示例不代表已核证。错误一次汇总且不回显输入和凭据；缺原件正文时给出已有来源的续读路径，不要求无关材料全文。修正完整对象后重提，未改字段沿用绑定草稿，不静默丢弃未知字段或猜改日期。发布事务最后核对来源资格、时钟、权限、底稿版本和真实数值口径。

## 运行控制与调度

`studio_runtime.model_work` 动态读取服务用户仓库外的 `model-work.json`；缺失、损坏或暂停都会阻止模型启动。在途等待也观察暂停并结束进程组。暂停保留输入和草稿，不冒充完成；恢复开关不会重放全部暂停积压。原始数据接收、确定性图表和组合计算继续运行。

本地模型调用保持暂停，研究 worker 不启用。云端自动研究还须满足 `RESEARCH_AUTOMATIC_ENABLED=true`、有效登记、最新 `Proposed`（拟投）或 `Invested`（在投）状态及当前权益研究范围。其他资产的风险调度独立检查适用市场日历，不因为研究暂缓就关闭风险能力。其他状态仍可阅读和私聊，不自动改动业务状态。自动风险研判仍按在投范围运行。

自动研究和风控的新任务只在北京时间工作日 09:00–12:00、14:00–18:00 之外领取，周末可领取；暂不引入节假日依赖，工作日假日采用同样保守窗口。该规则控制工作流启动，已开始的工作流允许完成，不在阶段中途强行重启。人工研究助手随时响应。网关实际计费由服务商决定，此调度不承诺费用折扣。配置与暂停操作见 [Server Deployment](SERVER_DEPLOYMENT.md#model-work-control)。

## 复盘、清理与验收

系统不生成强制每日反思、每周学习或自动 skill 优化。运行会话、专员输出、草稿、核证收据、原始依据、人工修改和发布版本供用户自行复盘。判断对错须区分当时可知事实、机制、反证、定价和实际结果，不用单次盈亏制造规则。

清理历史生成研究使用[数据库工作流](DATABASE_WORKFLOW.md)中的专用重置命令：先预览、停写、验证备份，再事务删除明确的生成结果。交易、账户、合约、行情、人工观点和资料按保护表摘要校验，不从本地整库覆盖云端。新研究不承担已废弃生成结果的兼容义务，原始事实与必要审计仍保留。

验收分别确认代码/接口、金融与来源边界、数据库和服务、页面实际交互、真实模型运行及内容质量。测试通过、HTTP 成功和工具可调用不能证明数据覆盖完整或投资结论正确；未成功采集和执行的能力须明确列为限制。
