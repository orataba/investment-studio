# 投资研究系统

本文是数据、量化、研究员、PM 与风控共同遵守的研究合同。服务及权限边界见 [Architecture](ARCHITECTURE.md)，工具及页面入口见 [Watchlist README](../apps/watchlist/README.md)，原始数据和信息时钟见 [Market Data Pipeline](MARKET_DATA_PIPELINE.md)。

## 目的与判断单元

系统帮助投资经理在当时可知的信息下，判断某个资产在当前价格、预期和组合约束下是否值得承担风险，并持续检查这个判断。新闻数量、报告数量、主题数量和 agent 数量不代表研究质量。

研究的基本单元是可修订、可追溯的判断。每次研究根据问题需要连接以下四层，不要求每条新闻都写全套文章：

1. **观察**：发生了什么、信息来自哪里、何时可知，哪些部分只是传闻、媒体转述或主观意见。
2. **机制**：通过什么渠道影响该标的的现金流、风险补偿、供求、流动性或制度约束；影响的规模、期限和反向条件是什么。
3. **定价**：原先的预期是什么，当前价格可能包含了多少，仍有什么条件未兑现。价格变动本身不能证明原因，也不能证明影响已经充分定价。
4. **决策含义**：方向、适用期限、当前吸引力、风险、把握程度和改判条件。组合行动另外结合实际持仓、集中度、相关性、流动性和实施约束。

业务改善不必然意味着证券便宜；证券值得研究也不自动意味着组合需要加仓。市场隐含预期、分析师预期、舆论关注和资金仓位分别取证。证据不足时保留条件判断，不把未知写成中性结论。

提出投资吸引力判断时，说明收益或风险管理价值从哪里来、适用期限，以及相关的价格、估值、收益率或产品费用与条款等依据，解释为什么补偿得了所承担的风险。依据随标的选择：基金 NAV 点位本身不能判断贵便宜，须结合策略、底层敞口、可比表现与产品条件。适合比较时，结合可比替代资产或持有现金的机会成本；不可比、缺少适用依据时明确限制，不能用“长期看好”替代当前吸引力判断。收益可以来自现金流、风险溢价、估值或预期修订、趋势、套利或组合分散等有依据的来源，不要求每个机会都建立在“市场犯错”上，也不要求每次研究都有目标价、概率或交易建议。

资产层面的判断进一步用于组合时，需要实际持仓和约束：解释它增加了什么收益来源、重复了什么风险暴露，以及流动性、融资、币种、对冲成本和可能损失路径是否可承受。没有这些输入时，保留标的研究结论及组合问题，不推定适当仓位。投资观点由 PM 保留决定与理由，研究员的建议不自动成为已采取的行动。

## 背景、变化与量化如何共同参与判断

变化必须有基准。上次可知状态、同口径历史、此前研究预期、公司指引、分析师共识和价格隐含预期是不同基准，分别保留来源和时点。分清实际经营变化、数据修订、预期修订、价格变化及敞口变化，不能把“增长”直接称为超预期，也不能把更新采集时间称为新的经营变化。

当前水平与变化路径共同决定意义。估值、偿债或流动性约束可能没有变化，却仍决定能否承担风险；增长放缓可能完全符合此前预期。重要更新需交代：相对哪个基准发生什么变化，改变了哪条判断、假设或损失路径，以及下一次什么观察能区分竞争解释。确认原判断也可以有价值，但不能以信息数量、主题数量或更新次数衡量研究进展。

基本面与量化可以各自提出假设、互相验证，也可以合理分歧。按资产和问题选择方法：

| 量化用途 | 对判断的作用与边界 |
| --- | --- |
| 状态与变化测量 | 观察水平、变化速度、波动、分布和可比相对表现；明确数据口径和观察窗口 |
| 假设与规律检验 | 当问题需要且有相应工具与样本时，检验关联、条件表现或预测；描述统计本身不证明规律、因果或可交易优势 |
| 估值与损失路径 | 用有依据的输入分析敏感性、情景和收益风险；主观假设与估计值分别标明，不制造概率或精确点位 |
| 组合影响 | 结合实际敞口、相关性、集中度及可取得的风险贡献检查边际影响；未覆盖的风险保持未知 |

量化证据不必服从基本面叙述，基本面叙述也不能被一个指标机械否定。两者冲突时先检查资产、期限、样本、信息时点与适用条件，保留仍无法解释的分歧及其决策限制，不用固定权重平均出综合分数。当前数值工具提供已实现的序列比较、价格风险及组合风险证据；未执行的统计检验或情景计算不得被叙述为已有量化结论。新方法按具体研究问题引入和验证。研究员也可通过隔离的 Python 工具对本轮已留存数据执行分析，保存问题、数据来源与时点、代码、参数、表格和图表。量化主题沿用方法重算，变更方法时明确说明可比性。工具不向代码进程传递业务数据库、凭据、网络访问或任意宿主文件权限；隔离运行环境不可用时明确报错，不降级到宿主裸执行。描述统计和探索结果不自动视为策略回测或交易授权。隔离环境和部署配置见[量化执行环境](../infra/research-quant/README.md)。

## 谁拥有哪一种状态

| 对象 | 内容与权威来源 | 更新方式 |
| --- | --- | --- |
| 原始证据 | 行情、财报、持仓、公告、资讯、PM 提供材料；保留来源与版本 | 数据系统摄取、修订、撤回，原版本仍可查 |
| 量化证据 | 真实输入、计算口径、共同样本和结果 | 确定性工具计算；模型解释结果，不心算替代数据工具 |
| 标的研究框架 | 对象、主要机制、研究重点、必要资料和反证方向 | 按实际标的维护；框架是询问方式，不是已证实的市场事实 |
| 适用方法与分析模块 | `research_plan` 组合公共方法；`research.modules` 保存各领域当前分析与覆盖 | 公共方法版本与标的补充分开；缺资料不等于不适用，局部复核不刷新其他判断 |
| 当前研究判断 | `research.investment_view`；唯一当前 AI 投资判断 | 按维度修订并保存版本；显式撤回后不恢复旧报告摘要 |
| 决策摘要与重要变化 | `decision_brief` 从当前判断提炼行动含义；`changes` 保存基准、前后变化、机制和决策条件 | 与底稿共同核证、留存版本；摘要绑定观点版本，观点变化但摘要未复核时不能继续显示为当前建议 |
| 事件 | 一次重要观察及其影响、来源、下一观察 | 同一事件追加实质变化；可关联多个主题，不复制事实 |
| 研究问题 | 一个可继续验证的具体问题及支持、反对证据 | 证据判断和跟踪状态分别更新 |
| 持续主题 | 围绕一个长期机制或投资问题组织相关事件、问题、预测和复盘 | 主题有自己的时间线；与全标的动态引用同一记录 |
| PM 投资观点 | 人类原意、作者、日期、版本及关联研究 | 人工直接保存或明确授权助手记录；AI 的复核单独归属 |
| 风控研判 | 当前范围内的研究、价格风险及真实组合输入 | 形成范围内的风险解释和待核实条件，保持输入时点 |
| 预测、复盘、经验 | 可观察主张、对原版本的检验、适用条件与限制 | 保留当时记录；失效经验可以撤回，不继续作为当前方法 |

研究报告的 `summary` 是某轮输出的叙述，不能成为独立续写的当前观点。运行检查时间、判断修订时间和来源可用时间分别保留。安静检查或失败尝试都不刷新旧判断的提出时间。

首次研究中，空白框架、议程或观点表示尚未建立研究，不能据此认定没有值得研究的变化，也不应等待 PM 替研究员指定方向。研究员根据实际标的、敞口和可用证据建立有用的研究任务、初始问题或有条件的判断；资料不足时写明具体问题与所需证据，不强制生成观点或主题。建立有用基线本身可以是研究进展。PM 档案的关注阶段是管理状态，不能被解释为投资上应当观望。

## 统一投资研究工作面

“投资研究”提供标的的完整持续研究，“投资观点”保留 PM 自己的判断和作者。报告采用连续阅读布局：开头直接呈现当前建议、依据、改判条件与重要变化，随后呈现重点主题及时间线、近期重要事项和适用分析。核心判断和变化无需逐个展开；图表就近解释对应的分析，避免把所有图形堆到一个量化区域。资料、框架编辑、历史版本与运行记录放在次级阅读入口。报告阅读模式使用同一底稿和版本，Briefing 行业入口进入相同阅读页，不持有另一套行业结论。行业首项以 XLK 实际成份为核心，产业链背景公司不进入成份加权口径。

共享标的身份、Watchlist 分类、经济敞口、管理方式和产品条款各有职责，不以一棵资产分类树决定所有研究方法。公共方法库 `data/research/frameworks.json` 维护经营与现金流、权益聚合、利率信用、供需、管理策略、定价补偿、市场量化、产品实施等模块；`research_methods` 从真实登记资料与专属方法生成 `research_plan`。分类和未知敞口只提供核查线索，不能直接当成持仓事实。直接债券尚未进入主工作面；利率信用方法用于已经支持的债券 ETF 和基金。

每只标的的 mandate 保存专属背景、机制、问题、资料计划和 `module_focus`，公共方法正文不再复制到新 mandate。用户重点、明确约束及用户选择的领域独立保护；研究员可以通过既有核证流程改进自己的专属方法，不能重写用户要求或公共方法。当前研究采用当前适用方法，各次运行保留实际使用的 `method_plan`。公共方法的实质变化提升该模块版本；旧分析显示待复核，不改变旧判断日期。

人工 `user_methods` 与 `report_preferences` 保存方法要求、摘要关注点、详略程度及次级章节偏好，研究员不能覆盖。章节偏好不能隐藏会改变投资决定的风险或变化。决策摘要不是第二套评级，也不自行生成仓位：`basis_view_version_id` 由服务绑定当前观点，读取时派生 `needs_review`；失配的原建议保留原日期，等待明确复核。

模块使用稳定 `key`，保存摘要、完整分析、证据覆盖、具体缺口、下一观察、来源与资料日期。`supported / partial / insufficient` 表达证据覆盖，不能当作看多看空或统一评分。未提交的模块保留原内容与检查日期，提交但语义未变的模块只更新自己的检查时间，接受的实际修订保留前版本。模块没有结果表示尚未建立研究，资料空缺不生成虚假数据。新写入统一使用 modules，旧 `fundamental_view / valuation_view` 仅通过集中历史读取映射为带原日期、原版本和原来源的 `prior_analysis`，不再维护平行当前字段或改写历史快照。

可视化使用 `figure_source_ids` 绑定已留存的计算、成份或预期快照，页面从实际值绘图并提供口径与来源。模型不提交任意 HTML、图形坐标或自造指标。研究工作面与阅读模式共用有版本的 dossier；独立数据浏览不冒充报告时点数据，当前总体观点也不从另一份运行摘要拼接。

## 新信息怎样进入持续研究

先检查真实性、相对既有信息的增量，以及对该标的的实际相关性。重要性由可能改变的投资判断决定，不用新闻热度或当天涨跌作唯一筛选。

重要程度、证据可信度、影响期限、市场定价和继续研究的价值分别判断；下面的处理方式是综合这些维度后的安排，不是互斥的金融事实分类。当前影响较小但可能揭示长期机制的信息，可以保留为有明确验证条件的线索。价格已发生反应只是一项观察；“基本反映、反应不足或过度”是带期限和假设的判断，允许暂时无法判断。优先处理可能改变当前决策且具有时效性的未决问题，不要求对每条新闻填满同一份模板。

| 情况 | 处理 |
| --- | --- |
| 重复、无相关性或没有决策意义 | 过滤；不制造用户可见研究动态 |
| 重要但影响短，且没有值得继续验证的剩余问题 | 简述事实与影响；保留来源，不自动建主题 |
| 事件仍有重要且值得继续验证的问题 | 先关联既有主题；没有合适主题时建立主题，说明下一观察与退出条件 |
| 新信息改变既有长期主题 | 更新对应主题的问题或事件；保留原始机制、反证及判断演变 |
| 出现独立且需要反复检验的长期问题 | 可建立主题，写清研究问题、为何重要、观察与退出条件 |
| 来源修订、撤回或原分析错误 | 触发重新核实并修订/撤回判断；保留原证据和原分析以便复盘 |

例如配售不能因为股价当天已调整就机械关闭。资金成本、稀释、资金用途、资产负债约束和未来资本回报可能仍待验证。反过来，没有可辨别的后续问题，也不应长期保留一个泛泛的“关注配售”主题。

同一地缘事件可以影响能源、航运、通胀和股票贴现率，但各标的要通过实际敞口和机制分别判断。共享原文不意味着共享投资结论；多个 agent 重复引用同一来源不构成独立证实。

## 跟踪生命周期

研究问题的证据状态为 `open / supported / refuted`，跟踪状态另为 `active / paused / closed`。获得支持可能只是验证了中间环节，不能自动退出跟踪；被反驳也不自动等于没有后续需要研究。暂停、关闭及重新开启必须是明确的状态变化，不能由模型默认值或没有新消息推断。

所有需要持续投入研究的事项统一归入重点跟踪主题，包括短期事件、基本面机制与量化特征。主题保存综合认识、最新实质变化、下一验证、重要程度和原因；不能拿最新一条次要问题代替综合认识。每只标的一般围绕五个最重要的问题、最多十个活跃主题，不凑足数量，也不在后台继续专门追踪被隐藏的低优先级事项。新增前检查重复、合并和替换；退出研究预算与问题已解决分别说明，历史仍可查。重要但无剩余研究价值的事件进入近期重要事项，保留事实、影响、价格反应及不再跟踪的理由。

关闭的理由包括：关键问题已得到足够回答、原机制已不适用、已无剩余决策意义，或研究范围明确改变。关闭保留结论、理由和历史。仅仅到期、价格反应、暂无新闻或证据不足都不能单独证明问题已经解决。暂停适合主动停止研究但仍可能恢复的事项。

自动研究可维护普通主题，包括用户提出的主题；提出来源与是否固定分别保存。只有用户明确固定的主题，其核心问题和生命周期保留人工控制。对停止跟踪的旧判断进行事实纠错，不应被误作自动重新开始跟踪。

## 每轮检查与长期连续性

每轮先读取绑定的当前档案和复核议程，回顾活跃主题的原始问题、综合认识、关键时间线、上次下一验证及关联投资观点，再决定需要取得哪些增量资料。主题本轮按继续、更新、合并、替换、暂停或关闭明确处理，安静复核只更新检查时间。初次建立主题先补充搜索和分析基线，不能把用户空白题目当成已完成研究。议程覆盖当前投资判断、持续问题、未结束事件、有效预测、预定日程、相关 PM 观点和有效经验。日程到期只意味着应该检查，不能作为事件已经发生的证据。

不同变化分开处理：

- 新的事实、反证、实现结果或观察窗口，可能要求更新具体问题、预测、判断或框架。
- 有研究进展但没有新的投资含义，可以只更新底稿。
- 已检查且没有实质变化，保留原判断和日期；不重复追加文章。
- 来源缺失、日期不明、搜索失败或资料尚未披露，记录具体缺口及它限制的判断。
- 运行失败保留最后完成结果和失败状态，不冒充一次有效的安静检查。

更新覆盖以最后成功的研究截止为基准，失败尝试不能消耗尚未处理的信息。运行分别保留资料准备、草稿生成、独立核证和发布阶段；可识别的暂时性服务故障允许有限重试，草稿和核证检查点沿用原信息截止与证据。重试仍须验证当前权限和底稿版本，不能覆盖研究期间产生的新判断；确定性的输入或协议错误需修复后再恢复。批量更新通过正常发布路径执行，不直接修改报告或伪造完成状态。

复核同时检查原判断的推理是否成立。发现旧事实错误或无依据的推断，本身就是应记录的研究变化，不需要等待新新闻或行情；仅修订受影响的判断，保留原版本。没有新证据可以保留一个未决问题，不能成为继续保留已发现错误的理由。

自动复核回执列出实际检查的原记录 ID。它说明进行了哪些检查，不能单凭“已复核”证明结论正确。未检查的项目保持原来的检查时间。每日时钟是检查机会，不是观点更新配额；基金月度净值、不同市场休市和 BTC 全天交易分别处理。

先前取得的文档仍是需要跟踪的对象。修订版本即使删掉原来的关键词或实体标签，也不能因搜索不再命中而漏检。比较原文版本与状态，用新证据重新评估，不能将修订后的正文回填为过去已知。这项检查针对共享原文库已取得的新版本，不意味着自动逐网址重新抓取全部历史链接。

## 数据足够与否，取决于研究问题

“工具可调用”“有报价”“有一份报告”和“足以支持当前判断”是不同结论。已绑定 FMP 身份的股票可先读取财报目录，按报表期、类型和财期选择季度或年度三表原始科目；页面的年度利润表简版不限制这条研究通路。目录、报表与科目缺失分别保留，不保证供应商对所有公司或市场都有完整覆盖。其他来源及资产仍按实际已取得资料研究，无来源的补齐数值不构成数据完善。

| 研究对象 | 需要按问题取得的主要证据 | 不能推断的事项 |
| --- | --- | --- |
| 公司 | 业务与经营指标、三表、资本配置、融资结构、同口径预期与估值 | 只凭收入/利润增长判断现金流和资产质量 |
| 股票 ETF / 指数 | 实际成份与权重、集中度、成份业务、预期覆盖、估值与跟踪方式 | 把成份公司 EPS 相加当 ETF EPS；用另一只基金替代实际持仓 |
| 债券/商品等 ETF 或基金载体 | 实际底层、久期/信用/供求机制、货币、对冲、展期或基差等已取得资料 | 给所有 ETF 套公司盈利框架 |
| 公募/私募基金 | 正确 NAV 类型与频率、基准及共同样本、持仓披露期、策略与条款 | 从平滑净值推断没有杠杆、流动性好或持仓安全 |
| BTC 现货 | 已完成行情、供给与网络/资金/杠杆等确实取得的数据、市场制度 | 从价格推断链上活动；套股票交易日和公司估值 |
| 组合 | 真实持仓、完整分母、币种、敞口、可用风险贡献和流动性约束 | 把 Watchlist 成员当持仓，或把权重当风险贡献 |

单位、币种、期间、复权/NAV 类型、信息时点、共同样本、覆盖率都属于数值结论的一部分。分析师覆盖进入/退出不等于预期上修/下修；零覆盖不能生成一个“盈利下降 100%”的研究事实。历史重算的 Regime/风险快照如不能重建当时可知信息，须作为当前分析工具使用，不伪装为历史预测。

共享资讯先检索再读取原始版本；辅助搜索用于实际缺口，检索结果不是已核实原文。搜索通道不可用需要保留缺口，已知官方原文仍可以定向读取；不能据此宣布没有重要新信息。

`read_stored_market_data` 提供项目已支持的财务、预期、ETF、宏观与商品数据合同目录，以及指定数据集、标识、日期范围的分页读取。目录标为未检查覆盖，实际读取才说明是否取得记录；所有读取绑定本轮信息截止。标准财务科目可支撑对应口径的分析，缺少财报原文或附注只限制依赖它的判断，不阻断其余研究。原始字段、单位、观察期和来源保留，不能因统一工具入口而假定各供应商口径相同。

## 人与 agent、研究与风控

PM 可以随时提出假设、记录判断、调整研究问题或要求研究助手继续调查。主观观点允许尚未验证，但必须归属清楚。AI 既不能把自己的想法冒充 PM 原意，也不能把 PM 的确信当作外部事实；分歧应转化为具体的证据需求、情景或改判条件。

新观点必须保存形成判断时的背景，系统预填的研究背景与用户判断分别归属；主题、事件、图表入口绑定原始版本、来源与时点，直接保存不依赖助手对话。单独新增可由用户填写背景，不强制先搜索。旧观点缺背景时明确展示“当时背景未记录”，不得用今天的资料补造当时依据。当前总体投资观点由用户明确选择某一观点版本；最新记录、补充判断、复盘和经验不自动替代它。删除已选观点会清除当前选择，但保留选择和观点修订历史。

原观点应能回到当时作者、版本和引用的证据。修订后的 PM 观点与之前的判断分别保留，事后回忆不得被写成事前预测。
PM 档案中的研究负责人和维护人不等于观点作者；旧记录没有作者归属时明确保留未知，不能据此补造作者。旧引用没有单独冻结原文时，按已保存运行和明确引用读取，并展示这项局限。

风控需要看到风险事项背后的当前研究条件、相关 PM 观点及未决问题，并结合实际持仓。它区分标的风险、组合暴露、已量化的风险贡献和未知事项。研究认为长期向上与风控认为短期脆弱可以同时成立，应解释期限和约束，不能机械投票出买卖方向。

事件的 `impact_level`（影响程度）、`urgency`（复核时效）和 `confidence`（证据可信度）分别保存。风险渠道、传导机制与行动条件进入研究和风控读取；未评估的程度与时效保持未知，不默认高风险。重大影响须解释机制，立即复核须给出具体决策条件；已有事项类别继续采用原有 `severity` 合同。

同类比较和研究资料按需分页读取，保留完整共同样本和来源。数值概览保留实际计算结果；完整序列、共同日期和原始输入通过同一个计算来源继续读取，续读不重算、不改日期窗口、不替换数据版本。大工具包被截断不能被当作研究员看过全部资料。可用的 Regime 状态仅在已绑定范围和时点内解释，没有取得时不得声称已综合宏观状态。

资讯检索先返回可续读的结果目录，完整覆盖说明与原文分别分页；零匹配须明确呈现。目录命中不等于已读原文，后续读取绑定原查询时点和文档版本。提交引用有误时，指出具体无效标识，保留其他有效引用。事实核证只能依据实际提供的原文、计算或明确标注范围的快照概览补正引用；资料存在于库中不等于本轮已核实。价格变化本身不能证明预期已充分计价，缺少适用估值或预期证据时须保留条件与未知。

## 复盘、学习与评估

复盘围绕原始预测或判断版本进行，分别回答：观察到了什么、机制是否得到支持、原定价判断怎样、还有哪些解释、当时可知信息下哪里做得不足。收益结果不能单独证明决策好坏；一次成功不能生成普适交易规律。

经验写明适用情形和限制，可由 agent 随证据更新或撤回。局部经验不自动改写所有标的框架；当多次反证表明框架遗漏了关键变量，应明确修订框架及适用范围，并保留原版本。人类随时可以介入。系统不会为了每日“学习”产生新规则、无根据阈值或评分。

评估区分三层：

1. **合同正确性**：原文与时点、数值可比性、当前/历史、生命周期、权限和实际读写行为。用真实故障和代表性跨资产情景做回归。
2. **研究质量**：相关性、机制、定价、反证、可检验性、行动意义和诚实的覆盖限制。独立事实核证是其中一环，不能证明因果或投资收益。
3. **前瞻决策价值**：随着真实观察窗口到来，审视遗漏的重要变化、错误更新、迟到的修订、无意义跟踪及原判断结果。样本及标准随问题和期限选择，不用统一命中率或短期收益给整个系统盖章。

当前采用一个负责研究的 agent 加独立事实核证，并使用确定性数据工具和版本化档案维持连续性。多研究员协作是后续可选增强；引入前应证明它改善特定问题的证据或判断质量，而不是以讨论规模代替上述基础。

研究生成与独立核证均运行在固定版本的 DeepSeek Harness 中，使用原生流式模型请求、工具循环及自动上下文压缩。压缩保留任务、判断和待办的工作记忆，原始证据仍按来源、版本及信息截止分页复读。研究生成可按需获取资料；核证 agent 只读取本轮固定的草稿、历史判断与原始证据，提交绑定草稿的核证收据，不联网补造依据或直接发布。草稿、响应合同与必需覆盖信息须完整交付，引用原件须有实质内容读取；目录或压缩摘要不能代替原文。应用在核证完成后统一校验来源、权限与底稿版本并发布。

## 版本收口与持续评估

版本固定四个研究入口的职责、证据与判断归属、时间和版本规则、跟踪生命周期及发布边界；标的观点、观察指标和具体研究方法仍按证据修订。新结构或新模型应解决实际研究问题，不因增加报告、分类或 agent 而扩展。

稳定版本须对应明确的代码与配置基线，并用实际覆盖范围内的代表性案例验证数据、计算、研究、发布和人工介入。验收关注：基本面改善但价格吸引力下降能否分辨；基本面与量化冲突能否保留和核查；没有新消息时价格或组合风险变化能否进入判断；弱线索能否以具体问题跟进；无变化、缺数据及运行失败能否正确区分；反证、结束跟踪和 PM 原观点能否保留演变过程。按适用案例检验，不要求每个标的展示同一套输出。

工程测试证明的是已测试的行为与边界。尚未成功执行的数据采集、搜索、模型调用或发布不能算已验收；当前记录为空或失败，也不能被解释为没有值得研究的机会或风险。真实研究产出的相关性、数值和推理连贯性需要单独审阅。长期决策价值在发布后持续观察，不以短期盈利、统一命中率或未到期预测作为定版的前置条件。
