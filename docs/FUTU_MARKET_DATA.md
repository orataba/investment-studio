# 富途仅行情接入

富途使用官方 REST Open API 和 OAuth 2.1 / PKCE，不运行 OpenD。接入只接受精确的
`quote:read` 授权；没有账户查询、交易、模拟交易或自选股写入接口。官方说明见
[OAuth 快速开始](https://open.futunn.com/zh-cn/api/overview/getting-started)、
[股票资料](https://open.futunn.com/zh-cn/api/quote/basic-data/stock-basicinfo)和
[历史 K 线](https://open.futunn.com/zh-cn/api/quote/basic-data/history-kline)和
[除权除息历史](https://open.futunn.com/zh-cn/api/quote/basic-data/rehab)。

## 日常使用

维护任务先同步证券覆盖目录。Watchlist 添加证券、Portfolio 证券选择器直接搜索本地统一目录，
显示行情来源；搜索过程不请求富途、不登记资产。用户选中后由原有共享数据维护命令自动登记并
获取行情，无需另外手工注册。重叠目录默认优先 FMP；若 FMP 币种与交易所核验的富途目录
冲突，新标的采用核验后的富途记录。已经登记的标的保留其来源，富途身份同时绑定稳定的
`stock_id`，不能因代码复用而接入另一只证券。

这是按标的确定来源的补充覆盖，不是在一次 FMP 请求失败后混入富途价格。已有其他来源的
价格或复权记录时，富途拒绝直接覆盖，需另行核对迁移。同一标的后续刷新和行情重试继续使用
已登记的来源。FMP 自己目录里有记录但历史接口没有数据，不会因此自动改源。

## 本机启用

```sh
bin/investment-studio market futu login
bin/investment-studio market futu status
bin/investment-studio market futu catalog-sync
```

`login` 首次自动注册 OAuth 公共客户端，打开官方授权页，回调仅监听
`http://127.0.0.1:60355/callback`。用户本人登录并只勾选行情读取，代码核验实际 token 的
scope；若返回账户、交易或其他权限，整次授权不保存。`--no-browser` 可打印授权链接，
`--timeout` 调整本机等待时长；回调端口在首次注册时由 `--port` 指定，已有注册不可暗中更换。

外部配置目录默认是 `~/.config/orataba/secrets/investment-studio/futu`，可用
`INVESTMENT_STUDIO_MARKET_FUTU_CONFIG_DIR` 指定。目录权限为 `0700`，客户端和 token 文件
为 `0600`；禁止位于仓库内。请求固定官方 HTTPS 域名、不跟随重定向、不继承环境代理，
凭据不进入日志、数据库或行情原始响应。token 自动刷新并串行加锁，刷新响应未给新
refresh token 时保留原值。授权失效时重新运行 `login`。

`status` 只报告本地保存的状态，不证明服务端授权仍有效。当前实现要求首次与刷新响应均明确
回传 `scope=quote:read`；供应商若省略或扩展 scope，会拒绝使用，而不会降低权限校验。

完成授权后，现有后台证券目录同步任务也会更新富途目录；未授权时明确跳过。
可单独运行 `catalog-sync --markets hk` 或 `--markets us`。

## 目录、数据口径与覆盖

- 候选身份来自 HKEX 的证券清单和 Nasdaq Trader 的 Nasdaq / Other Listed 清单；随后按每批
  最多 400 个代码请求富途基本资料。全部批次成功后一次发布，移除的覆盖写入明确 inactive
  观察；失败保留旧目录。HKEX 为各报价柜台提供实际币种；美股普通股、ETF 的 USD 为美国
  上市市场约定，记录 `currency_basis=us_listing_convention`。
- 仅接明确定义的普通股、ETF；不把富途泛称的 ETF/信托类别直接当作 ETF。HKEX 单列的
  杠杆反向 ETP、REIT、债券、权证，以及缺乏明确分类的美股品种目前不自动纳入。目录不是
  “全部港美证券”的承诺。缺少上市日期的富途记录也暂不自动登记；已登记证券继续使用其现有来源。
- `futu_security_catalog` 是应用搜索目录；`futu_security_directory` 是采集时重新核对的稳定
  `stock_id`、品类和上市日；`futu_raw_eod_daily` 保存原始日线和来源。它们复用现有公共
  数值库、原始响应、PIT 时钟及数据包协议，不需要新增数据库表。
- 目录命中只证明富途识别证券，不证明账户有所有行情权限或历史日线完整。首次添加会验证
  实际日线响应；空数据、权限问题、身份变化、欠缺请求起点或最近已闭市行情仍明确报告。
  请求起点按上市日与已配置历史起点中较晚者的首个实际交易日判断；较短历史保持 `partial`，
  已有连续区间的收益仍可使用。重新选择已登记证券不更换来源，即使尚无首条报价也一样；
  变更 FMP/Futu 来源仍需单独审核迁移，Futu 重选不会重写已有来源、历史边界或选择策略。
- 本地安装可复用香港日期当天已完整成功发布的港美目录：核对最新批次状态、所需市场、
  采集与发布时间、批次计数和当前目录一致性，并明确报告已复用目录。缺少合格快照时正常
  同步，失败仍报错；不会回退旧目录掩盖失败。日常定时目录维护仍按原流程联网刷新。
  目录采集从联网前即进入现有 `writing` 批次；网络、验证或发布失败均留下 `failed`，
  成功时才把采集明细和完整计数与目录原子发布，避免较早成功记录掩盖同日后续失败。
- 日线请求固定 `ktype=2, autype=0, extended_time=0`。按最多 365 个自然日分窗（小于单页
  370 条上限），不用文档中日期与毫秒混用的翻页参数。校验市场当地日期、OHLC、成交量精度、
  重复记录和证券身份；所有窗口完成才发布行情批次，回采不得丢掉已保留的日期。
- 采集窗口与风险监测、简报共用已确认交易所收盘时钟，含半日市和夏令时；收盘后定时
  刷新会请求当日已收盘行情，不再被固定 17:00 的旧截止规则退回昨日。请求区间内缺失
  任一已收盘交易日时，保留原始响应、列出缺失日期并拒绝发布批次，不假设停牌或补零。
- 实测批量调用会返回 HTTP 200 内的 `ret_code=-11 / rate_limited`；按服务端提示等待后
  重试，默认瞬时错误最多三次尝试，每次等待最多 60 秒（最多两次等待，共 120 秒）；
  HTTP 401 另允许强制刷新 token 后重试一次。超过 60 秒仍明确失败并报告
  供应商要求的等待秒数，不提前重试。HTTP 429 / 5xx 也有同样的有界重试；
  其他业务错误不会当作限频反复调用。这不是服务商公布的固定额度承诺。
- 单日收盘价超出当日高低区间时，保留响应证据并拒绝该批次，不发布价格或 TR。
  仅开盘价超出区间而收盘价仍在有效高低区间内时，原始值保留并标记 `ohlc_quality=inconsistent`；
  该收盘价仍可作为独立价格点，该日异常 K 线不进入正式 OHLC 序列，刷新结果
  明确报告不完整与异常条数。若该日已有正式 K 线则阻止整次投影，要求核对；不会修改高低价
  来制造一致性。非正数、非有限价格或最低价高于最高价仍直接拒绝。
- 批量与定时刷新分别报告覆盖质量和已提交的事实变化：`partial` 保持不完整状态，只有市场
  数据或计算输入水印推进时才以 `canonical_changed=true` 触发下游重算；相同证据重放不会
  因历史异常重复通知。定时任务只重试 `failed`，不重试 `partial`；历史单条异常会持续显示
  在标的刷新说明和任务的 `partial` 数量中，不阻止其余正常收盘价与总收益更新。
  即使最终状态为 `failed`，只要返回的水印证明已有事实提交，仍通知下游，且跨多轮重试保留
  这一标记。通知成功包括 Watchlist 重算入队确认，不等于异步重算已完成；通知失败仍明确报告。
- 原始行情只写 raw OHLCV 和 `close`；`return_semantics=price_return` 仍描述这个原始基础。
  交易、估值使用原价。另以保留的公司行动证据派生 `adjusted_close` 和同日期的乘法因子，
  总收益选择只接受经过覆盖核验的 `adjusted_close` 段，不回退原始价格。

手动采集与查询示例：

```sh
bin/investment-studio market futu collect HK.02822 --start 2025-01-01 --end 2026-10-07
bin/investment-studio market numeric query futu_raw_eod_daily --symbols HK.02822
```

## 公司行动、乘法复权与内部总收益

每次行情补采或刷新都调用仅行情 `corporate-actions/rehab?divi_mode=include_divi`，保留原始
响应，并在 `futu_corporate_actions` 写入一个按证券版本化的完整快照。`events_json` 保留完整
事件数组，`stock_id`、上市日、覆盖期间、实际观察时间与原始文件引用绑定这份证据。官方合同
称接口返回自上市以来的全部事件；此处的完整性标记为 `provider_reported_since_listing`，
不是已独立审计的穷尽性证明。

- 已确认的普通股票收到成功且明确为空的事件数组，记为 `covered_no_actions`。
- ETF 的空数组记为 `unknown_empty_etf`，因为官方说明 ETF 往往没有该接口覆盖；不会把
  空数据自动解释成未派息；有事件的完整响应仍须逐项解释和核对覆盖。
- 数组缺失、失败响应或身份不符不能充当无事件证据。未来尚未闭市日期不能扩大已覆盖区间。
  补采旧价格时，新取得的公司行动快照仍按实际取得时的最近已闭市日期界定覆盖。

本系统的方法 `futu_declared_cash_reinvestment_v1` 使用原始收盘价和来源声明现金，不使用
富途前后复权 A/B 算式。令 `P` 为原始收盘价、`D` 为每股现金，普通除息日的收益倍率为
`(P_today + D) / P_previous`，并假定现金在除息日收盘全额再投。已核对旧/新股数的单独
拆合股事件使用 `P_today × new_shares / old_shares / P_previous`。每段从首日原始收盘价锚定，
此后按实际现金再投份额计算 TR 比例水平：

- canonical `adjusted_close` 是与该 TR 成比例的乘法复权水平；
- `adjustment_factor = adjusted_close / close`，同一个因子用于原始 OHLC 的乘法展示；
- 前复权与后复权显示只改变同一段因子的锚点，原价显示保留原 OHLC；不提供富途加法复权
  产品路径。TR 作为收益、风险和比较的内部基础，不作为额外价格展示模式。

生产响应实际给出 `per_cash_div`，与文档示例的 `dividend` 字段有差异。普通现金事件必须有
可严格核对的来源说明，例如“1股派股息0.38573HKD”，并且金额与数值字段一致、币种与登记
报价币种一致。这里的每股基数是事件当时的股份：AAPL 2020-08-07 的 0.82 USD 是随后
1 拆 4 之前的每股现金，不能再次按现有股本缩放。原始证据中的其他描述形式、外币派息、
特殊派息、供股、分拆、送转股、组合行动或金额/基数冲突目前不能自动转换。单独拆合股也需
基数和结果股数均明确，且与来源比例一致；不会从 A/B 因子反推现金。

`total_return_tax_basis=gross` 和 `total_return_tax_treatment=no_investor_tax_deduction`
是本模型的约定：使用来源声明现金全额，不扣投资者税费。富途 REST 合同没有明确说明其所有
来源现金的税务处理，故这不是已核实供应商全市场税前金额的声明，也不模拟任何账户实际到账
或交易。金额证据标记为 `provider_declared_cash_per_contemporaneous_share`。

无法解释的事件、缺失交易日或除息日收盘价会切断相应收益链接。事件日可以成为下一段的新
锚点，后续有覆盖的段仍可使用；禁止跨段计算收益。`total_return_segments` 明确列出可用
段的起止日期；`total_return_unavailable_intervals` 给出被切断的两端日期及原因。因此断点
两端本身可以是有效价格，不能仅因端点与不可用区间相交就删除整个后续历史。

每次投影重新读取全部已保留原价，生成 `futu_return_daily`，每行绑定原价与公司行动的
`source_id`、批次、原始文件引用、方法、段号及不可用原因；失效日期也写入明确的空派生值。
公司行动取自最新成功价格采集批次明确绑定的 `corporate_actions_batch_id`，不是无条件取
动作表的最新记录。若采集在动作存档后、价格发布前失败，单独留下的动作快照不能改变 TR；
缺少绑定则只保留原价并报告收益证据不足，不回退到未绑定快照。
canonical 的旧 `adjusted_close` 撤回、OHLC 因子清空/更新、覆盖与方法元数据在同一资产行锁
和数据库事务中完成，推进现有市场数据与计算输入水印。已成功的证据修正会重算旧历史；同一
证据重放保持 canonical 水印不变。此处没有新增业务表，也不会改变实际交易或账户数据。

## 部署边界

本机与云端分别使用本环境的私有配置和授权。OAuth 文件不随行情数据包或数据库备份发布；
安装代码或复制公开行情不代表目标环境已取得行情接口授权。云端启用时须配置私有目录，
经受控回调通道完成本环境授权，不能把 callback 服务暴露到公网。REST 账户权限、地域限制、数值限频及数据使用授权以富途实际
账户和 REST 服务为准，不套用 OpenD 的额度表。
