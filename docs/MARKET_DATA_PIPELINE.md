# 共享市场数据与资讯

Investment Studio 自己持有公开数值采集、历史库和应用数据。外部市场资讯采集服务
`market-information-feed` 负责抓取、初步清洗、原始内容留存和文本包；不生成日报、周报或研究报告。
旧数值数据库只作为一次性迁移源，运行时不导入其 Python 包、不打开其数据库或读取其密钥目录。
文本从 2026-09-07 的正常采集重新积累，不迁入旧项目的文本历史和报告。

## 数据归属

| 数据 | 所有者 | 存储与使用 |
| --- | --- | --- |
| 全市场证券目录、日行情、财报、预期、成份、宏观等 | Studio 共享数值层 | `market_data` 目录与最新投影；不可变 Parquet 历史及原始响应 |
| 新闻、公告、事件、观点、舆论 | 资讯采集服务输出；Studio 接收并保存 | `market_text` 版本索引、数据包回执、原文与渠道覆盖 |
| 登记资产身份及应用使用的行情／净值／FX | Instrument Data | `instrument_data`；公开数值按原有单位、币种与复权合同投影 |
| 邮件、私有附件、净值候选、解析状态 | 私有摄取层 | `data_ingestion` |
| 账户、交易、FCN／期权合约、账本 | Portfolio | `portfolio`，不进入公开数据包 |
| 投资观点、底稿、事件判断、风险跟进 | Watchlist | `watchlist`，原始资讯按不可变版本引用 |
| 状态识别的物化输入、模型及结果 | Regime | 自有数据库和运行目录；来源读取 `studio_market` |
| 日报／周报 | Briefing | `briefing`，保存版本、输入引用和生成记录 |

共享数值没有第二套完整 DuckDB；DuckDB 仅查询 Parquet。全市场数据积累不受观察列表范围限制。
消费者用数据集和不可变来源 ID 查询，不直接遍历其他项目的文件布局。

## 数值范围与 PIT

- 美股：证券目录及退市／代码变更、日行情、分红拆股、公司资料、标准财报及字段、分析师预期／评级／目标价、ETF 成份及披露、财报事件、宏观与市场序列。
- 原样财报、SEC 目录和评级细项历史支持显式指定证券补采；不宣称所有细项都已全市场每日刷新。
- A 股、港股及其他登记资产通过已有 FMP、Tushare／DataHub 与权威来源适配接入；按实际权限与数据覆盖记录缺口。
- 万得全 A 通过 Wind MCP 固定刷新，原始响应及未复权日线保留在共享数值库，验证后的价格回报序列投影到登记资产；范围、时钟及额度失败规则见[万得全 A 日线](../shared-data/README.md#万得全-a-日线)。
- 富途 OAuth 仅行情接入补充港美股与 ETF 目录，按标的固定来源；目录预同步、搜索本地读取、选择时自动登记。独立原始日线不混入 FMP 的复权序列，详见[富途行情接入](FUTU_MARKET_DATA.md)。
- 期货只保留日频及其他低频事实。分钟行情、分钟衍生数据与旧 Parquet 重复导出不迁入，也不排入采集。
- 分析师预期按公司、年度／季度、完整采集轮次保存。A→B→A 是三个观察，空的完整快照不会复活已撤掉的预测财期或成份。
- `observed_at` 是实际捕获时间，供应商明确的发布时间另存；历史查询必须满足相应可用时钟。今天回补的修订财报不能伪装成多年以前已经知道的数据。
- 旧资料中的异常未来财期和明显不匹配会计年度不进入可用事实，迁移回执记明排除数量与理由，原始证据仍保留。
- 财报推断的预期币种保留推断来源；不能用股票报价币种填补未知的预期币种。

`us_eod_daily.close` 是拆股调整价；`raw_eod_daily` 保存未经复权的 OHLC，并另存供应商的分红调整价。
Portfolio 的登记行情投影使用后者，保留 GBp 等报价单位转换与复权因子合同。报表价格变化明确展示两端实际交易日，不将价格收益称为含分红总回报。

FMP 与富途的证券采集、登记行情投影共用已确认交易所收盘日历，包含假日、半日市和夏令时。
登记资产以交易所 MIC 为准；未知日历明确失败，不根据代码猜一个工作日。每次刷新固定一个时钟，
采集与投影使用同一截止日，港股含收市竞价最晚结束时刻（正常 16:10、半日 12:10）。
因此 16:30 定时任务能够请求当日已收盘行情，不再被固定 17:00 截止退回昨日。
增量采集检查本轮原最新观测日至应有收盘日之间的交易日；返回一条最新价格不能掩盖其中的缺口。
真实有效的新价格可以入库，缺失仍明确失败，并由风险读取拒绝受影响收益区间，既不补零也不删掉缺口。
定时任务另按本轮开始时钟核对成功结果的实际原始收盘尾部，并把验收记录写入任务摘要；
`no_new_data` 或合法的 OHLC `partial` 状态本身不能证明尾部行情完整。验收只针对本轮处理资产，
不会在其他市场收盘后、其任务执行前要求全库立即更新。

收盘可采集与发布到期分开：没有正数发布延迟合同的日频行情，当日已收盘但尚未取得的观察在
市场本地跨日前记为等待发布；已到期的前日及更早历史缺口仍失败，不补旧值、不改真实 as-of。
显式正数 `release_lag_days` 继续按已完成交易日计数，不再叠加一天宽限。Watchlist 相对于已到期
观察仍为 `fresh`，以 `awaiting_publication_date` 单独说明当日等待，风险历史样本/路径缺口合同不变。
定时采集摘要的 `listed_close_coverage.pending_count` 独立保留等待数；即使采集执行成功，仍会允许
既有 23:00 结算补刷，不把等待视为最终覆盖完成。

FMP 登记行情全历史投影还逐日核对上市交易所的实际闭市日历。周末／休市日的供应商观察保留在
不可变公共证据中，不进入当前 canonical 行情；重放会将历史误入的报价置为不可用、移除其当前
OHLC 展示，并推进原有市场水位。Watchlist 的上市证券收益、图表和报价选择也排除已知非交易日，
历史 read model 通过 materialization 版本重建。基金披露的非交易日 NAV 和 crypto 24/7 观察不套用此规则。

证券代码不是永久证券身份。已核验的代码复用、改名和终止区间保存在
`price_series_identities`，连同证据引用及真实观察时钟一起复制。发现新代码变更、稳定身份标识变更
或当前／退市身份冲突时，先隔离受影响的价格序列，核验后使用现行供应商代码完整重建同一证券历史。
普通 `query`、`latest` 只读取当前身份对应的完整重建批次及明确绑定它的增量；未完成重建或身份不明时
返回明确不可用原因，不复活旧证券的行情。更早的 `as_of` 仍按当时已知事实判断；
`versions` 和不可变来源读取保留全部原始证据。旧代码有效期之外的公司行动不能触发该证券的复权任务。
登记 FMP 刷新使用该次完整查询的身份来源与完整重建批次，不能用限窗或分页结果替换 canonical。
身份隔离或缺少完整代次时，即使补采失败，也将该投影报价明确置为 `unavailable`、移除当前 OHLC，
并沿既有市场／计算水位通知 Watchlist 和 Portfolio；普通暂时性采集失败不撤销仍合格的历史。
首次经核验的完整代次可重建未绑定的旧投影并记录 `source_provider_security_id`；绑定后 ID 改变必须
走明确的登记资产迁移，不能自动将另一证券接到原资产。重建会撤销新代次之外的旧日期，不拼接跨证券收益。
现有非 FMP 行情需要先审查源迁移，FMP 投影不能覆盖其他所有者的历史；原始公共历史始终保留。
若供应商仅按更名前后代码分别提供历史，维护为同一 `security_id` 下的独立价格片段：
旧代码的 `history_end` 截至最后有效日，新代码的 `history_start` 从生效日开始，各自使用原代码完整回采。
这些边界限定可用价格片段，不表示证券终止或新设；读取和复权仍按 `symbol` 隔离，
不得因身份相同就拼接不同复权代次，跨代码连续收益历史仍不可用。
零值、非有限或缺失的供应商复权价格属于源端失败，原始响应和失败回执保留，不用普通收盘价代填。

港股尾部缺少日线时，交易日历先确定应有的闭市日；FMP 补采后仍缺失的日期再核对港交所逐日行情表。
`hkex_security_sessions` 留存官方证券交易状态和收市报价。只有全部缺失交易日均明确无成交、币种一致、
官方收市价与最后真实原始收盘价一致时，才可以认定当前报价仍有效；停牌、有成交、证据缺失或价格不符
都不能获得豁免。最后成交日期保留原值，不生成虚构日线，也不按周末一概消除历史缺口。
港交所说明逐日报价通常在交易日约 19:00 提供、补充表约 20:00 提供
（[官方产品说明](https://www.hkex.com.hk/eng/ods/historicalDataProfile.aspx?ProductID=3pN9lZCQ7TuPMcfzJeTqOutmOv1IJIEMQu44fJg8yrg%3D&SchemeID=N7QQbtusjlfU2cE31yjTGBDjo3fMhaMm3KK0cxB4Hp8%3D)）。
因此 16:30 收盘刷新可能已获得全部有成交证券的价格，但无成交核验仍等待当日报价表；
这类报告不可用会明确指出 HKEX、证券和日期，不能当成 FMP 价格接口失败或无成交证明。
晚间补核继续使用同一证据与验收规则；报告尚未发布时仍保留未确认状态。

FMP 的 `market_series_daily` 按可识别的 series／日期隔离不合格数值：保留整份不可变原始响应，
严格校验后只发布有效日期；非正数或冲突重复记录所在的整日不进入本次可用事实。身份不符、
结构错误或无法定位日期的响应仍整份拒绝，不按周末无条件过滤，也不修造缺失价格。
OHLC 高低区间矛盾也按坏日排除，不扩张高低价来迁就开盘或收盘。
XAUUSD 与 DXY 的源端日线时钟尚未确认：采集仅以此前完整 UTC 日期作为请求上界，
不借用 NYSE 交易日历；报告继续标记 `observation_schedule_unverified`，不据此认定收益区间完整。
包含坏日的批次在 `details.validation` 保留 `status=partial`、有效行数、拒绝日期、原始行索引及原因，
原始响应仍由 `raw_ref` 追溯。这里的 batch `ready` 只表示有效事实及证据可以发行，源／采集阶段仍为
`failed`，消费者不能把它作为完整历史；后续重叠采集可以继续发布新的有效日期，不能清除旧失败回执或
覆盖 PIT 历史。异常旧日不能阻塞同源有效新日。
这一规则仅用于市场序列，不改变股票复权补采必须完整覆盖历史后才能写完成 receipt 的合同。

Regime 的指数、汇率、现货和加密资产原始报价同样按日期隔离异常，保留仅有收盘价的来源合同。
采集批次、复制后的读取来源和模型输入 manifest 都保留相关质量证据；源初始化不能把部分有效响应
标为完整成功。后续有效响应可解除当前读取范围内已纠正的警告，历史证据保持不变。模型是否可用
仍由既有交易日覆盖与样本要求判定，不通过补造价格或降低模型门槛处理源端异常。

恒生 12 行业及 HSCI 基准使用官网 `valueHistoryPub` 公开接口，13 个 PI 代码和解析由共享
`hsil` provider 统一持有。返回必须成功、身份精确、日期唯一且收盘值有限为正；保留真实采集时钟。
不使用旧 `chart.json` 地址、备用域名或总回报指数代替。Regime 副本直接读取已有规范化历史与
原批次来源，不为接口迁移重写旧原始响应。

## 文本与研究

每条资讯分别保存首发、事件发生、源端观察和本端接收时间。只有日期时保留日期精度，未知时间保持未知。
来源提供摘要、付费墙片段或无法取得正文时按实际完整度标注；初步清洗不允许把模型推断改写成原文。
修订、撤回和重复来源可以追溯，不能仅用 URL 覆盖旧版本。

研究追踪先分页检索共享资讯，再读取绑定版本原文，按需要补充在线搜索。新抓取的原文同样进入共享库。
资料不足、未检索、来源失败和未发现重大新增是不同结果；研究可以完成有限分析，但必须保留覆盖不足说明。

日报／周报均通过受限 DeepSeek Harness 生成。数值变化在程序中计算，模型解释绑定输入并结构化提交引用。
首轮形成草稿后，独立校稿会话重新阅读所引原文，核对事实、条件、时间与归属；校稿提交成功后才形成完成版本。
正式报告由云端 `publisher` 生成，本地为 `preview`。周报重新读取整周窗口，历史补录与本期新资讯分别说明。

## 两端运行

外部配置位于服务用户的 `~/.config/orataba/secrets/investment-studio`：

- `market.env`：明确数据库、公开数据目录、`ROLE=collector|replica`、源密钥文件路径及传输位置。
- `briefing.env`：Briefing 数据库、API 回调和 `EDITION_ROLE=publisher|preview`。
- 原有 `data.env`：私有摄取、登记资产投影与结算；行情供应商密钥也必须指向本项目自己的秘密目录。
- `portfolio-copilot.env`：现有 DeepSeek 凭据；不会传给公共数据包，也不会把数据库凭据交给 Harness。

公共市场数据由云端集中采集。常驻本机使用 [每周云端同步](LOCAL_MACOS_SERVICE.md#每周从云端同步)
统一接收市场资料和业务数据库；两端服务独立运行，本机修改不回传，下次快照以云端为准。
完整同步启用后停用本机单独的小时级 market-sync 计划；包导入入口保留用于独立恢复和数据接入。
两端登记范围可以不同。仅在本地使用的公开证券，可在云端 `market.env` 的
`INVESTMENT_STUDIO_MARKET_ADDITIONAL_INSTRUMENTS` 中维护 FMP 代码到资产类型的 JSON 映射
（如 `'{"APLE":"equity","600900.SS":"equity"}'`）。它只扩展每日参考资料与分市场收盘行情的
公共采集范围，不在云端创建业务标的、列表或研究记录；新增本地独有证券时应同步维护此采集配置。
本地 Regime 使用 `studio_market_regime_reader` 读取共享数值，只获 `market_data`
schema 的 `USAGE` 和表的 `SELECT`。云端采集进程使用独立的 `studio_market_regime_writer`，
只获数值库现有五张事实／发行表所需的读写权限；两个账号均无私有账本或 schema DDL 权限。
市场库迁移在这些账号已由部署环境创建时重设上述权限，并维护新表的默认读取权限。
同库升级备份和回滚保留原 ACL；跨实例导入若省略 ACL，须先按部署合同配置账号并执行统一迁移。
共享对象目录的默认文件 ACL 必须允许 Studio 与 Regime 的运行 UID 读取对方的新对象，并在目录中创建对象。
数值原始响应、数值包导入和文本原件通过 `mkstemp` 原子发布；新临时文件在发布前设为 `0640`，
使继承的具名读取 ACL 生效，同时不给其他用户权限或给另一写者原地修改对象的权限。
这些入口不修改已存在对象的权限；部署时须单独核验历史对象的 ACL，私有目录不适用此公共对象合同。
数值原始响应以解压正文的 SHA-256 命名，新 gzip 统一时间和平台头。历史压缩封装不同时，
导入先核验传入文件的 manifest 大小及压缩文件哈希，再严格核对两端正文均匹配路径中的哈希；
只有规范 raw gzip 路径允许复用本地原件，其字节和权限保持不变。损坏或异正文仍拒绝，其他
不可变对象继续要求大小和文件哈希完全一致。恢复同步直接重跑既有入口，无须重写历史原件或删除回执。
资讯包分别送达两端；Mac 离线后逐包补齐，成功回执才推进接收状态。接收时间保留本机真实时钟。
追数同时核对数据库的实际导入记录，外部传输回执不能代替数据库事实。恢复较早数据库后，仍在发行目录中的缺失数值包和资讯包会重新导入；已经退役的数值包缺批次时明确要求从采集端生成新的恢复包，不会报告已追平。
数值目录仍只有采集端原有 `index.json`。接收端通过同一受信 SSH 和远端标准库 Python 读取：
未变更时只传哈希与大小确认，变更时流式 gzip；完整解压并核验大小及 SHA-256 后才原子缓存目录。
连接限时 10 秒，目录传输最多 300 秒，解压元数据上限 64 MiB；数值包本身的传输、验收及逐包回执不变。
目录缓存按远端位置隔离，每轮仍核对本地实际 ready 批次；远端不可达或数据损坏时不使用旧缓存冒充追平。
失败回执记录真实耗时、已收字节和是否收到远端头部，避免把连接等待、正文传输与导入混为一谈。
本地数值同步或每周完整云端快照发布成功后，会唤起已安装的 Regime `catch-up` agent，按最近已结束交易日补跑。
Regime 的 `replica` 角色只加载 API、清理与补算任务，不另排来源采集或每日训练，也不在登录时自动补算；
计算随成功的数据同步触发，避免对尚未送达的数据反复失败。已有运行由 launchd 和 Regime 全局锁串行处理。
完整快照的回执单独记录补算请求；请求失败保留已发布快照，后续到期检查仅重试补算请求。请求已受理不代表模型已完成，完成状态以 Regime 的运行记录为准。
数值与文本分别判断成功；文本接收失败不阻断已成功数值的应用投影。Regime 唤起、行情投影和资料投影也分别完成，任一步失败仍使本轮返回失败，保留真实诊断供后续补跑。
Mac 通过已信任的 Tailscale SSH 入口连接资讯采集服务器，不依赖其局域网地址。

数值定时采集、发行和复制由 `infra/scripts/install_market_pipeline.py` 安装；它仅写定义，启用是独立部署操作。
每周任务更新证券目录、公司资料以及指数当前成份和历史成份事件，已有历史族持续积累。证券目录请求显式保留 FMP 全部股份类别（`includeAllShareClasses=true`），以证券代码为单位保留同一发行人的不同上市股份，不按公司合并。采集时间与各市场闭市日期分别判断；大型全市场批次不会阻塞登记资产收盘价采集。FMP 参考资料在公共采集成功或副本收到数据后统一投影到登记资产；部分失败只投影已完成证券并保留失败明细。独立盘前参考资料任务仅保留 Tushare 来源，不重复读取同一批 FMP 投影。
FMP 授权 API 使用普通 HTTPS，显式协商 gzip 并流式解压，256 MiB 上限作用于解压后的内容；不采用浏览器 TLS 模拟或第二套传输回退。连接／读取超时、HTTP 短体及 gzip 截断／损坏沿用最多三次尝试；不完整 CSV 不进入发布。读取超时约束无 I/O 进展的等待，不代表整次下载的总时限。公司资料 bulk 分页保留每页至少 60.1 秒的间隔，分页完成与 ready 批次才是采集进展依据。
参考资料的公司／ETF 简介及补充字段读取已有 current 投影；历史截止时点不满足可见性时仍读取 PIT 历史。
完整预期和持仓快照只扫描本次选中的文件，但保留整个历史及其他 scope 的字段并集和类型提升。
同一批登记资产复用一次查询连接及未变化文件集的 schema，查询仍逐次选取实际快照，不持久缓存资料或增加另一套失效机制。
仅资料投影的价格更新数仍为零，不改观察时钟、不触发 NAV 重算；这一计数不能用来判断资料是否发生变化。
价格全历史返回空数组、缺少已留存交易日或最新应有收盘价时仍明确失败并保留原始响应与待完成请求。
空价格不等于接口不支持、已经退市或当天无成交；资料的 active 标志也不能替代生命周期或交易日证据。
可选参考资料的完整空响应可以标记 coverage unavailable，两者不能混用成功口径。

## 首次迁移与存储

```bash
bin/investment-studio market numeric migrate-source /absolute/old/data
bin/investment-studio market numeric migrate-source /absolute/old/data --apply
bin/investment-studio market numeric export-bundle /absolute/bootstrap.zip
bin/investment-studio market numeric import-bundle /absolute/bootstrap.zip
```

迁移流式读取原始观察与响应，成功的数据集重复执行会跳过；不要为恢复失败任务而无差别使用 `--reimport`。
批次元数据和原始来源 ID 随数值包传递，导入不改写旧观察时钟。迁移完成后核对回执的源行数、可用行数、排除数量及空间占用。

大规模首次入站包会额外占用一份空间；容量规划需要同时计入规范数据、原始响应和发行包。本地已具备全部批次时直接跳过该包下载。
后续增量包保留到两个接收端都能恢复；容量规划以实际留存与增长测量为准，不假设压缩率。

PostgreSQL 备份只包含目录与业务数据，**不包含 Parquet 和文本原文文件**。
完整备份必须同时包含公开数据目录；执行备份／恢复时先停止共享写入与报告生成，再保存数据库及对应不可变对象。
只恢复 PG 元数据不能恢复共享数据。已有项目 schema 备份、恢复和迁移脚本已纳入 `market_data`、`market_text`、`briefing`。

Regime 云端来源容器也会写入 `market_data`。共享 schema 迁移或还原前，必须等其当前来源采集退出，并暂停对应的 autonomous source timer；操作完成后恢复。Studio 的停止任务集合不包含 Regime 原生 units，不能代替这一步，也不表示所有共享写入已自动停止。
